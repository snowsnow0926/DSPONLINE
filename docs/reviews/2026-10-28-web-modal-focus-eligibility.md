## 定位证据

上一轮冻结运行 `8f018da9d473` 的 179 个 JavaScript 与本轮隐藏映射重建逐字节相同，其中 176 个有 sourcemap。独立停止时间线未丢事件，共 205,478 个事件、39,332,996 B；约 164.4 ms 的最长帧包含两个不重叠的样式重算，分别 31.482 / 33.542 ms。第一个嵌在约 121.85 ms 的 React 调用中，不与该调用重复相加。

第三次独立样式查询诊断确认，该处约 34.4 ms 的读取目标是 `BODY`：`tabIndex=-1`、没有 tabindex 属性，原判断最终不会聚焦它。查询时工厂仍带挂机隐藏 class，随后 React 改变该 class，再发生样式重算。该诊断主动读取懒求值的 display/visibility，有额外开销，不进入正式对照。
