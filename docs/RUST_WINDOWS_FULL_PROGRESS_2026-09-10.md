## 最新这一批做成了什么

这一批修复了“已经退出，旧结果却又把运行状态恢复”的并发问题。退出发生在准备接管、接管确认或恢复过程中时，现在会拒绝迟到结果；已经排队但尚未发送的命令也不会在退出后继续发送。

同时把上一批的会话失效信号接到实际运行控制器。失联后会立即取消时钟、停止新操作，已交给 Rust 的工作保留原来的持久恢复方式。这只是停止控制，尚未开放完整实时运行权限。

三个新负例先在旧代码上复现失败，修复后通过。相关 202 项检查、完整 Native 回归 981 项通过，另有 1 项 Windows 权限条件跳过，类型检查通过。真实助手释放及被终止都能停止 main 运行控制器；其中用于激活控制器的玩法回复是测试替身，不能算成真实 Rust 活跃模拟。

源码 **891e87fa** 已提交，新包 **1.2.7+891e87fa2d9a** 已冻结并通过包内停止信号检查，全程零窗口、零聚焦、零弹窗。**本批没有新增游戏提速百分比**。[完整修复记录](./reviews/rust-windows-runtime-lifetime-2026-09-10.md)
