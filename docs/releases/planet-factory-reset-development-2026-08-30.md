# 星图一键重置星球工厂开发报告

> 日期：2026-08-30
> 状态：开发完成，未签名、未部署、未发布

## 目标

为星图中的已殖民星球提供一个明确的“重置星球工厂”操作，使玩家可以在不重开存档、不破坏星区身份和全局进度的前提下，彻底删除一颗星球的玩家工厂并重新规划。

## 最终语义

### 永久删除

- 该星球上的全部玩家建筑、建筑堆叠和资源节点上安装的采集设备。
- 该星球的传送带、线路运行数据和相关跨星物流航线。
- 该星球的物资托盘、施工队列、手搓队列、建筑制造任务与直供缓存。
- 该星球的生产方案、书签、区域、视口和局部工厂指标。
- 如果时间扭曲控制器位于目标星球，关闭设备并清空尚未提交的时间负债。

上述内容不返料、不送入其他行星、不可撤销。

### 保留

- 天然资源节点的 ID、位置、资源类型、当前剩余量、初始容量和枯竭小数余数。
- 星球殖民状态、行星生态档案、工业角色和自定义名称/备注/标签。
- 科研、无限科技、戴森云/球工程、量子仓库、全局施工库存和随身舰队。
- 蓝图库、累计产出、累计挂机和其他全局进度。
- 光标当前托住的物资；如果其来源建筑被删除，只清除已失效的来源引用。

## 安全与一致性

- 三次确认分别展示删除范围、不可撤销后果和星球精确名称；第三次只在完全匹配当前显示名称时可提交。
- UI 预览不是权威依据。最终命令边界会再次读取实时存档，只允许已殖民且确有工厂数据的行星。
- 跨星航线按既有取消语义终止。货物在本引擎中于航线完成时才从源站扣除，因此取消不会吃货或复制；已预扣翘曲器退回仍存在的载具所属站。
- 清理所有外星站点指向已删除站点的 peer、供应游标和量子过渡桥，不留悬空实体 ID。
- 因滚动产率是多星球混合窗口，不能安全从历史样本中减掉一颗星球；重置后从当前模拟时刻重新采样，但不修改累计生产值。

## 大存档内存边界

领域命令不调用通用的整档 `copyState()`，而是只克隆会被航线取消或引用清理改写的小部分对象。最终提交会清空撤销/重做历史，不保留可重建已删星球的逆补丁。这是一个功能正确性约束，同时避免 96 MiB 级终局档在删除瞬间因存在新旧两份工厂而峰值翻倍。
