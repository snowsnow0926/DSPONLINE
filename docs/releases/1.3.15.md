## 玩家修复

配方和物品选择器改用旧 CSS 内核可识别的视口约束，支持横竖屏及大字号下的列表滚动，标题和关闭按钮保持可达。接管成功后的主动刷新明确延续本页身份，可选导航接口缺失不再跳过身份存储；已关闭页面遗留的普通短租约可在加载玩家状态之前安全到期。旧页面的写入 fence、存档冲突选择及原生权威边界保持。

用户提供的视频还出现快速结算校准保守提示。本批保留原算法与决策，验证选择精确结算可进入工厂，测试库存 42 保留。完整受控复现和此前阶段记录见[问题分析](../reviews/2026-11-14-mobile-scroll-writer-takeover.md)。原机型号、系统和浏览器版本尚未知，受控复现不代表已经完成原机回测。

GameState v47、envelope v2、云 schema8 和 SQLite layout3 保持。当前 API 自身源码与共享合同核对一致，50 个合法字段和 30 个非法字段检查通过，无需切换服务端代码。
