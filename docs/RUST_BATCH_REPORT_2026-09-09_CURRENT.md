# Rust 本批开发报告｜2026-09-09

这批已经测到了实际等待时间的改善：在 Windows 开发包中，一个包含 **9,107 个实体、20,000 条传送带**的公开测试工厂，完成同样的 5 秒离线收益，从点击继续到能打开设置，等待中位数由 **20.79 秒降到 5.96 秒，缩短约 71.3%**。存档结果逐字段一致，保存后两次重开也一致。

这是一项已验证的开发成果。当前整个版本的回归检查仍有失败，尚不具备发布资格；线上版本和下载没有在这批中更新。以下数字对应已冻结的 `2bb10b43` 开发包，不把后来只改测试和文档的提交号写成它的构建号。

最新补测中，你提供的 **11 万实体、23 万条传送带**终局档已通过 **9 秒 Rust 与完整 JS 结果对照、取消不损档、取消后两次重开**。新的隔离开发包包含保存优化，但完成结算后仍未在原 90 秒内进入工厂；成功结算的持久保存和重进仍待验收。所有测试隐藏、静音、正常退出，原档保持不变，见[新包与终局取消记录](./reviews/rust-rp1-private-cancel-2026-09-09.md)。

这轮又减少了一项实际开销：保存同一份终局档时，主线程不再重复生成六份大型编码缓冲区，避免累计约 **646 MB 临时分配**。主档、上一版备份、快照和存储大小记录均复验一致；专项 130 项、类型检查、完整本机单元 **3,170 通过 / 39 跳过 / 0 失败**通过。源码已推送 `7fd6d521`；新云端单元、构建及 Linux Server/Ops/原生检查通过，完整浏览器仍有 **29 项失败、23 项重试后通过**，Windows Rust/Native 通过，游戏单元 3,169 通过 / 39 跳过 / 1 项矿脉长挂机超时。新包从干净 `37630d05` 构建，其运行代码与 7fd 相同。它减少了保存中的无用分配，但尚未证明峰值内存下降或整体进入速度进一步提升，见[保存优化记录](./reviews/rust-rp1-save-byte-length-2026-09-09.md)。

## 这批具体做了什么

首先，把普通游戏存档真正连接到 Rust 离线计算入口。原来部分验证依赖提前准备好的原生检查点；现在普通保存来源也能上传到本地 Host，生成候选，经过完整检查后再保存，并通过实际游戏入口重开。

其次，减少大存档读取时大量细碎的底层读取，使用有界缓冲；仍核对完整数据和哈希。随后清理 JS 参考计算中的无用扫描、无关库存复制和重复建设规划，让跨语言结果校验更有效率。这几项收益不能互相相加；上面的 71.3% 是最终新包重新跑出的完整等待对照。

最后，落实你的后台测试要求：测试窗口隐藏、不抢焦点、静音，并使用实际离屏绘制。本批八个实包场景共 **32 次启动和正常关闭**，没有显示窗口、聚焦或原生弹窗。一次只跑一个本机测试任务，低优先级运行；完整模拟和私人存档测试至少保留 6 GiB 可用内存才启动，运行中触及 2 GiB 停止线则由独立监控终止本次测试。不会关闭你的其他程序来腾资源。

1. **浏览器回归仍有缺口，一组恢复检查已在本机及云端通过。** 前一轮 c6 有 15 份挂机失败现场（含重试）尚未完成初始化；测试现先等运行时就绪，再执行原停止/保存断言，相关 13 项在本机及新 0ce 云端全部首次通过。0ce 完整浏览器仍有 34 失败、20 重试后通过，涉及画布、设置、菜单耗时等，需逐类诊断。截图和轨迹已经留存，不能统一归因于旧问题或机器慢；[本轮记录](./reviews/rust-rp1-recovery-test-startup-2026-09-09.md)保留原结果和修复范围。
2. **多线程验证前提修复已取得云端证据。** 短任务可能在另一条线程参与前就由一条线程完成；专项加入有界等待，保留原参与数量和完整结果断言。修正后的正常优化核心在本机及新 Windows 云端均 **1,113 通过 / 5 忽略 / 0 失败**。它修复测试的调度前提，不代表历史堆损坏根因已解决，原失败保留。见[本轮记录](./reviews/rust-rp1-worker-participation-2026-09-09.md)。

## 当前进度与下一步

现在处于 **RP1“离线加速实际入口”已取得收益、完整阶段验收继续进行**。可以确认“一个代表性大工厂确实等得更短，而且结果能安全保存”，不能把它写成“Rust 已全面接管游戏”。网页/安卓 Rust、长离线自动采用和实时模拟接管仍是后续阶段。

下一批优先定位并减少终局档保存流程的重复工作，完成成功结算后的真实菜单、持久保存和重进验证，同时逐类处理浏览器回归，再依据测量结果推进有界长离线。保持原 1–30 秒采用范围、数据保护和性能门槛；测试继续后台运行。Windows 开发包目前为 `NotSigned`，合并、安装升级、正式签名与发布检查另行完成。
