## 剩余风险

- Windows 安装程序仍为 `NotSigned`，Windows 可能显示未知发布者或 SmartScreen 提示。
- 本轮没有连接物理 Android/iPhone，也没有重新执行真机覆盖升级、30 分钟温度、耗电和帧率测试；包名、递增 versionCode、APK v2/v3 和长期证书连续性已验证。
- 没有使用生产账号执行认证后的云存档写入 smoke；这是生产数据保护边界，不应以临时玩家数据替代。
- 主题选择写入新的设备级 localStorage 键，但当前设置更新路径仍同步保留旧 `GameSettings.theme` 字段，且设备键缺失时会读取旧存档主题；因此“主题完全不进入 GameState”的字面门禁尚未彻底满足。GameState 版本、云 schema、SQLite layout 和确定性模拟规则均未变化，后续应由开发角色移除兼容镜像并补充存档/云 payload 断言。
- 香港根盘在发布窗口约 78% 使用，上海约 79%；均低于 90% 硬保护线但接近 80% 告警线。备份和旧发布目录应继续按既有异地归档策略监控，不得删除当前版、回滚版或有效备份。
