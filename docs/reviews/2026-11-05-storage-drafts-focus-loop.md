## 修复内容

| 问题 | 原因与修复 | 保持的边界 |
| --- | --- | --- |
| 可选存储被拒绝时界面发生错误 | 离线选择、检查器布局、原生 Beta、旧离线实验读取在错误处理前取得 `localStorage`；开发多核选项也未防护。将取得存储本身纳入保护，返回原有默认值 | 离线仍“询问”，不自动放弃收益；Beta 不自动开启，多核实验无权限时关闭；不修改结算算法或主存档 |
| 教程因进度读写、迁移或配额异常打不开 | 设备记录读写防护；旧记录可读但复制失败时仍返回旧完成项；组件不再在调用前取得全局存储 | 原修订键、迁移优先级与去重保持，不删除记录 |
| 切换同名对象时串用草稿、迟到 IME 事件误提交 | 输入按草稿身份、敏感模式及提交模式建立独立编辑会话 | 同对象日常刷新保留 DOM；失焦提交与 forwarded ref 保持 |
| 横竖屏同一次更新丢失尚未发出 input 的中文 | 旧布局清理捕获原生预编辑，新布局在清理后恢复；初始化不在 StrictMode 检查中重复覆盖 | 草稿仅页面内存；显式清除/替换优先，密码不进入共享草稿 |
| 光标选区或多层弹窗返回焦点丢失 | 同次替换可交接焦点/选区；限定文档和弹窗范围，微任务后令牌过期。弹窗读取当前入口引用，子弹窗继承已移除父弹窗的动态入口 | 不抢玩家已移动到别处的焦点；稍后重开手机输入不自动聚焦；失效入口安全回退 |

卸载捕获和延迟 effect 不会复活明确清除的草稿；敏感字段切换为普通字段不转移敏感正文。焦点令牌只存 DOM 范围及选区数字，不存正文或凭据。
