## 第一层交付

1. 建造、空建筑回收、单线拆接与蓝图部署采用记录级写时复制；未变化记录保持引用稳定。
2. 主线程编辑改为带 revision 的精确 patch；Worker 使用稳定运行时索引和 8,192 上限的 dirty 集合。
3. 撤销/重做保存正向与逆向差异，默认最多 40 项且约 32 MiB；撤销不覆盖之后已确认的模拟时间。
4. 大工厂模拟仍逐步精确推进；相邻 UI 大投影累计发布，玩家命令、选中、放置、连线和时间扭曲不节流。
5. Canvas 使用轻量显示索引；延迟回执不触发无投影全量重建。
6. React Flow 节点交互使用稳定事件代理，阻断“旧节点回调保留旧 App render 和旧节点数组”的代际链。
7. React 单在途发布器识别 no-op 同对象更新并立即释放槽位，避免 Worker 已更新而托盘/侧栏永久停留旧状态。
8. 大档自动保存由 Simulation Worker 以最多 8 个区块一批流到页面 IndexedDB writer，逐批 ACK，manifest 最后提交。
9. 成功保存后释放约 77 MB 菜单 raw envelope 缓存；分块回退 Worker 严格 single-flight，空闲 5 分钟终止。
10. 内存保护只暂停当前可见状态并保留模拟债务，不安装旧检查点；关闭保护时内存和积压水位不会主动回档。

架构边界见 [状态所有权与生命周期](./1.1.9-windows-performance-layer1-architecture.md)，小白版与开发版数字见 [开发与对比实测报告](./1.1.9-windows-performance-layer1-report-2026-08-26.md)。
