# 网页物品拖取反馈：满仓提示

- Role: develop；基线 `ede1f2cb`，沿用 D 盘工作树和 `codex/content-pack-cloud-fixes-20261107` 分支。
- 来源：玩家称开始时能拖走矿堆几百个物品，后来只能点击拿 100；用户补充平台为网页版，尚未确认落点与托盘剩余容量。
- 判断：单击上限 100 是现有设计；直接拖入物资托盘按其剩余容量批量转移。未发现网页版暂停或运行时的通用拖拽失效。

## 复现与修复

以不含真实玩家数据的 547 个铁矿石夹具验证：

1. 暂停时拖入空托盘：547 全部转入，矿堆归零。
2. 运行时拖入空托盘：同样全部转入。
3. 托盘已有 1,000/1,000：拖入不转移，但此前没有解释；单击仍可拿 100 到光标载荷，矿堆剩 447。

修复 `App.tsx` 的满仓拒绝反馈：显示“物资托盘已满，未执行拖入……”，说明物品保留在建筑、可腾出空间或提高上限。关闭运行记录时也显示，沿用现有四秒提示。没有改变物资、容量、光标上限、模拟、存档或原生命令。

这是一种能解释玩家表现的已复现场景，不能据此断言玩家当时就是满仓；若其托盘有空位，仍需要具体拖动落点或游戏画面继续排查。
