# 供电快照共享试验：网页收益不足，已撤回

本轮试验没有保留运行代码。局部供电刷新耗时减少约 23.9%，但真实网页两组对照的峰值只少约 36 MB（0.65%），进入等待、进入卡顿与退出卡顿均未改善。上一轮大档保存后台空闲回收仍保留，约 105 MB 级存档和备份设置保持；整体性能目标继续，未发布。

## 做了什么，为什么撤回

任务 `2026-10-27-web-power-sharing`，角色 develop，P1，来源为香港网页版持续性能优化授权。候选仅在不可变供电快照中复用未修改的实体与运输线，控制器和旧格式缺省字段仍复制，普通模拟保持完整复制。这样能避免大部分记录分配，但增加了共享引用的维护边界。

先前五阶段记录显示，渲染进程峰值在进入产率复制时已经从约 3.2 GB 升到 5.5 GB。检查了恢复日志处理：其清洗仅过滤无效历史采样，没有确认整档 JSON 克隆，不能把它写成已知瓶颈。另一项 `createSimulationProjectionStateIndex` 初始化也只保留数组引用，并没有重新建立大 Map；这两个方向没有据此改运行代码。

独立局部试验更快，而整页收益不足、卡顿样本还略差，因此撤回共享方案。这里只否决本次实现，不声称证明所有共享方式无效，也不把小样本波动当成稳定的性能退化结论。

## 固定输入和完整结果

沿用约 105 MB 级主档；原始附件 107,637,967 字节。205,464,026 字节是展开并预热的测试表示，不是玩家存档翻倍。上轮固定实际保存正文为 110,673,715 字节（105.55 MiB），本轮没有重写原件。

四次固定输入试验按旧/新、新/旧顺序，使用同一只读准备态；旧版引擎/量子源码固定为 `c0d1a9182a07f499d8a54870c0e747fc84880cb9`。候选复用 110,042 个实体中的 110,041 个和运输线数组。两次旧版、两次候选的完整供电结果 JSON SHA-256 均为 `fa4b11d37ea8c011d9d025db9497d40238ec616902015c57e95576d36b3bbea5`；随后 1 秒普通模拟的完整状态均为 `36d8f79cfb611b984990406fde10e3303428d4d77df023a87702eb134579497d`。输入全文哈希保持，实体与运输线数量一致。局部中位 386.60→294.25 ms，减少 23.89%；该数字不代表整页加速。

## 真实网页结果

四次独立、未开启 CPU/堆诊断的隔离 Chrome，顺序旧/新/新/旧，使用真实界面。均保留复制档库存，预热至少 40 模拟秒，8 倍产率复制运行 5 秒，停止后观察 3 秒。无构建或其它测试并行。
