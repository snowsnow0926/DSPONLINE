# Rust RP1：终局档冷开准入复用

Role: develop。2026-09-08。本地持续开发阶段，未发布。

## 结果与边界

对用户授权的 107,637,967 B 终局档（110,042 实体 / 233,300 条带），三对独立新旧 Host 进程采用 AB/BA/AB 顺序。所有配对运行期间，本任务没有同时运行构建或其他测试。测试驱动固定为 `b3f3465d`，源档、完整输出哈希在六次运行中均相同，原文件大小、mtime 和 SHA 不变。

| 指标 | 旧 Host 中位数 | 新 Host 中位数 | 缩短 / 减少 |
| --- | ---: | ---: | ---: |
| 原生 `coreOpen` RPC | 14.032 秒 | 9.281 秒 | 33.9% |
| Host 私有提交内存采样峰值 | 2,335,293,440 B | 1,370,873,856 B | 41.3% |
| 开档后 Host 私有提交内存 | 374,005,760 B | 372,027,392 B | 0.5%，基本持平 |

三对时间均改善，旧/新范围分别为 13.927–22.221 / 8.601–9.764 秒。旧版第三次明显更慢，保留该原始样本；样本量仅三对，不能宣称所有设备固定提升 33.9%。内存峰值六次采样 p95 均 63 ms、最大 63–72 ms，无读取错误，符合原 50 ms 目标间隔、p95 ≤ 100 ms / max ≤ 250 ms 门槛。

测量包含原生检查点恢复、解析、索引、准入与完整 canonical 校验；不含 JS 种子准备、导入、画布、用户界面或离线结算持久提交。内存指标是 Host 进程的私有提交，未合并 Node/renderer/Worker，也不能等同于物理驻留内存或完整玩家等待。RP1 完整离线闭环仍未完成。

开档已经解析了全部实体，本地物流、星际物流和戴森准入原先又各自完整解析一遍。新增接受只读解析切片的内部入口；冷开复用已有实体，原来的独立解析入口继续存在。长度、实体顺序、目录、所有路线/归属/中转检查、发射目标和原拒绝优先级保留。戴森独立入口仍先验证基字段形状，再完整解码后检查目标，避免改变错误顺序。

## 诊断、失败及验证

首次两次独立诊断将约 2.33 GB 的峰值定位到准入阶段，耗时约 4.49 / 5.26 秒。补齐三处后，一次有效阶段诊断的准入降至约 1.95 秒、峰值 1.36 GB；该带日志样本不混入正式 A/B。

旧 `Process.Refresh()` 采样器在中间候选及首轮 A/B 中出现 p95 108–109 ms，原批次保持失败。新采样器仅以查询权限打开指定 Host 句柄，读取相同的私有提交指标，频率和门槛保持不变。真实 64 MiB 提交、独立读数对照及原驱动测试 6/1 opt-in 跳过通过，类型检查通过；正式六次使用同一新采样器。具体 API 来源见[测试基线](../TESTING_RELEASE.md)。

- 准入专项 3/3：17 个正常/错误场景，以及切片长度拒绝、源实体字节、状态 SHA 和修订不变。
- 完整 debug Core 1,104/5 ignored/0 失败；与 release 构建并行运行，不作为速度样本。
- 新 Host 差分 50/1 opt-in 跳过/0 失败；立即关闭和退出生命周期 1/1，涵盖延迟/同步释放及 1/2/4/8 worker。
- 新 Host 真实终局档一秒 Exact 1/1，完整结果与 JS 相同，无差异字段、原文件不变。与编译并行，仅证明正确性，不报告推进速度。
- 完整 release workspace 1,351 通过 / 5 ignored / 0 失败：Core 1,104、Host library 244、Host binary 3；严格 Clippy 全 workspace/all targets/release 通过。
- 公共长离线首轮 12 通过 / 2 超时失败 / 2 性能跳过。有限矿和量子容量的 8 小时 Exact 回退用例均触及原 360 秒测试上限，未生成完整状态对照结果。该轮与编译及其他正确性检查并行；保留原失败，正在相同 Host、相同门槛下分别以独立进程复验，不能先归因于负载或计为通过。
- 有限矿独立复验仍失败：300 秒 Host 请求超时，约 323.5 秒完成原 `finally` 关闭流程；没有同时运行其他本任务编译或测试。冻结旧 Host 同场景也触及 300 秒请求超时，约 331.0 秒完成清理。两次失败不证明结果不一致，也未取得完整状态资格；它们否定“仅在本轮冷开修改后才超时”，但尚不解释相比更早 189 秒整项记录的变化。量子容量不继续重复旧候选，转由下一项精确回退优化后的新 Host 完整套件重新验收。
