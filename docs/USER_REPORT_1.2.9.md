# 1.2.9 开发说明

2026-09-10。开发候选，尚未发布到线上。

这次把能够共用的性能优化带给网页和安卓，并增加两项画布操作。不是完整的跨端 Rust 版本；玩家可以先获得这一批已经落地的收益。

## 玩家能用到什么

| 内容 | 使用方法与效果 |
| --- | --- |
| 保存优化 | 在支持 Worker 和 IndexedDB 的环境中，减少保存准备、校验和自动恢复快照的重复处理。完整校验、备份和失败保护继续保留。 |
| WASD 移动画布 | 按住 W/A/S/D 向上/左/下/右移动视野，可组合斜向移动。松键停止；输入文字、打开弹窗或切到别的窗口时不会持续移动。安卓连接键盘时也可使用。 |
| 框选生产区域 | 打开框选工具，启用“同时选中生产区域”，把区域边框完整框进去，再拖动选中的节点。区域边框会跟着节点移动。 |
| 直接选择整片区域 | 点选生产区域，在编辑条点击“选中区域与内部节点”，再拖动节点。触屏端会切到布局模式。只选择完全位于区域内且未锁定的节点。 |

区域与节点的这次移动可以一起撤销、重做、保存和重新打开。区域边框仍能独立调整大小；这个操作不会改变配方、库存和传送带连接。

## 实测收益怎么理解

公开合成测试工厂包含 **9,107 个实体、20,000 条传送带**，原始数据约 4.1 MB。同一台电脑、同一存档，交替比较已发布的 1.2.8 源码与本次候选，三组正式测试均更快：

- 保存确认时间中位数：**694.1 毫秒 → 469.5 毫秒**。
- 少等待约 **224.6 毫秒，降低 32.4%**。
- 最终保存状态、备份、恢复快照都经过比对，结果一致。

这个数字只代表上述场景的“主存档保存确认”，不代表游戏整体快了 32.4%，也不是安卓真机测速。安卓会使用相同的优化逻辑，具体收益取决于设备和存档。

约 108 MB 的授权终局存档已经完成双方预热校验；正式对比触发了内存保护而停止，因此还不能给它一个可信的提速比例。玩家原存档没有修改。

## 当前交付边界

两个新操作、共享保存、挂机停止失败后的恢复和导出、安卓启动恢复、手机横竖屏与大字号均有通过的专项测试。21 项画布与恢复回归通过；正式 1.2.7 网页资源升级、断网重开和旧存档完整保留也已通过。

最终网页和安卓签名包已从 `0521eb63` 构建，包含手机结算报告误弹退出提示、偏出屏幕的补修。原存档可以在最终网页包中升级、离线重开并继续保存。

**安卓最终留档验证尚未通过。** 早期候选能覆盖升级并进入旧工厂；最终包复验时，这个模拟器的底层存储损坏，被 WebView 重建为空库。另建的全新设备在启动旧版 1.2.8 时，也因主机内存不足被保护程序停止。原因尚未查清，不能宣称最终包的安卓留档已可靠验证。所有模拟器现已关闭，玩家数据未动。

上一候选完整云端回归还有六个失败，包括冷菜单 P95 627 毫秒（目标 500 以内）和暂停画布峰值帧 849.9 毫秒（目标 800 以内）。相应用例在本机通过，但不能替代云端结果。最终提交的云端回归已启动，尚未结束。

源代码、测试和候选包已交付，**暂未上线**。线上站点、正式下载和玩家云存档未因本次工作而更改。制品和待解决事项见 [开发交接](./RELEASE_HANDOFF_1.2.9.md)，过程证据见 [开发记录](./DEVELOPMENT_1.2.9.md)。
