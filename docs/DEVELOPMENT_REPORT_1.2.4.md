# 1.2.4 开发与验证报告

> 状态：开发实现已完成，当前工作树尚未冻结为 clean runtime commit，也没有签名、不可变发布清单或生产部署。本报告只记录本地开发与验证事实。

## 1. 交付范围

1. 云存档单修订硬上限提高到 256 MiB，并同步 Web、Windows、Android、API、调度器和活动 Nginx 的有界传输合同。
2. 设置页和跨标签页只读提示增加“强制接管本页”。接管以当前页面为准，旧标签页立即失去写入权。
3. 内容包建筑可以声明 `smelter`、`assembler` 或 `chemical` 通用配方族，解决黑雾熔炉和制造台无法复用基础配方的问题。
4. 时间扭曲“产率复制挂机”只复制宇宙矩阵、小型运载火箭、太阳帆、科研投入和逐恒星系戴森终局事件；普通矿石、燃料和中间件不再复制。
5. “内存或模拟积压超限时自动暂停”改为设备默认关闭；缺失、损坏或不可读取的设备偏好均按关闭处理，明确保存过的开启/关闭选择继续保留。

GameState v47、存档 envelope v2、cloud schema v8 和 SQLite layout v3 均不变。

## 2. 256 MiB 云存档边界

统一合同现在采用以下字节边界：

- 保证正文：96 MiB。
- 单修订硬上限：256 MiB。
- 明文兼容兜底：30 MiB。
- 压缩请求：112 MiB。
- 解压正文：257 MiB。
- 并发展开预算：320 MiB。
- 单档响应：544 MiB。
- 传输最长 600 秒；本地压缩最长 180 秒。
- 活动 Nginx 模板为 `client_max_body_size 128m`、读写 660 秒并关闭请求缓冲。

服务端会在直接上传声明的原始字节超过 256 MiB 时，在读取大正文前返回 `SAVE_SIZE_TOO_LARGE`。账号总配额、槽位配额和 30 MiB 明文兼容路径没有被绕过。256 MiB 是单修订硬上限，不代表任意不可压缩的 256 MiB 正文都能穿过 112 MiB 压缩请求边界；正常 JSON/gzip 大存档属于目标路径。

## 3. 标签页强制接管

接管流程使用 IndexedDB 串行读写事务推进 fencing token，即使旧租约仍有效也能明确接管。随后流程为：

1. 当前标签页取得新的写入令牌。
2. 旧标签页收到租约广播后停止模拟 Worker、纯挂机 Worker、后台结算和自动保存，并转为只读。
3. 当前标签页把当前内存状态保存为主档；正常备份机制保留接管前主档。
4. 保存路径执行 checksum、正式反序列化和读回校验。
5. 旧标签页尚未提交的纯挂机恢复日志被安全收口，但不发放收益。
6. 当前页刷新并从刚验证的主档重新进入。

存档冲突状态仍必须先由玩家选择版本，不能用强制接管绕过冲突处理。兼容存储后端只允许本页成为主写者，不伪造跨标签页持久租约。

## 4. 内容包与玩家插件复核

附件 `dsp辅助工具_浏览器插件_v1.6.zip` 仅作为不可信数据解包和静态检查，没有执行其中脚本。附件事实：

- ZIP：4,370,412 B。
- SHA-256：`BD9863F7333DBEBFDE1871FCE5BC8E98712F76B8F9048E523C4B57577078EE66`。
- 完整黑雾包：23 个物品、6 个建筑、24 个配方、0 个科技。
- 黑雾制造台声明 `family: "assembler"`，黑雾熔炉声明 `family: "smelter"`。

游戏端此前丢弃 `family`，且配方匹配只比较具体建筑 ID，导致两类黑雾建筑即使声明设备族也不能使用基础通用配方。1.2.4 会校验并保留该字段，再按同族匹配实时配方目录。静态注册完整包后，制造台可见 50 个制造配方并包含齿轮，熔炉可见 15 个熔炼配方并包含铁块。

插件自身还存在独立缓存陷阱：默认脚本加载精简包，完整包行被注释；两份包又共用相同 ID 和版本 `0.1.0`，而插件只在版本变化时替换缓存。插件开发者切到完整包时必须同时提高版本号，或改为按内容指纹更新；否则浏览器可能继续使用旧精简 manifest。游戏端不伪造插件版本，也不执行附件脚本。

## 5. 产率复制终局白名单

算法标识升级为 `pure-idle-replication-v2-endgame-output`。材料白名单固定为：

- `universe_matrix`
- `small_carrier_rocket`
- `solar_sail`

科研投入、逐恒星系火箭发射和壳面帆吸收继续使用各自的终局计数，不与普通库存混为一类。最近 60 个模拟秒、不足时 30 秒的正向统计和锁定供电倍率规则不变；速通禁用和无限科技门槛不变。测试明确断言铁矿石不会获得复制增量。

## 6. 内存与积压自动暂停缺省值

该开关仍是设备级 `localStorage` 偏好，不进入 GameState、存档、云同步或确定性哈希。1.2.4 只调整“未做过选择”的缺省行为：新设备、缺失键、损坏值和存储不可用均为关闭；精确保存的 `true` 或 `false` 仍按玩家选择读取。关闭时堆水位与 24 秒模拟积压不会主动暂停，但 Worker 协议、检查点和显式内存分配失败保护继续生效。
