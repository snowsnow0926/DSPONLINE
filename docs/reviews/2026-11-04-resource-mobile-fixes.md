## 资源利用规则

原先采集速度已经覆盖流体，但储量减免只应用于固体矿脉。现在所有资源点使用同一个减免系数：每级减少 10% 储量扣减，Lv.10 起不扣储量。水、硫酸、原油、普通和稀有固体矿全部覆盖；天然无限海洋与无有限矿储的轨道采集沿用既有规则。

这项减免作用于采集时的储量，不免除工厂配方、燃料或制造用料。有限流体同样通过既有的 `resourceDepletionRemainder` 保存 0～9 的整数余数；旧档缺失时按 0 读取，已有余数和显式剩余 0 保留。GameState v47、保存格式和字段契约保持，未读取或改写真实玩家存档、云数据或备份偏好。

在线引擎、离线/宏观资源核算、星球枯竭预估、Rust 精确/宏观结算及资源显示同步使用该规则。科技说明及英文翻译一起更新。

新增 14 项单元检查覆盖当前目录的 16 类资源、Lv.0/1/5/9/10/15、分段模拟、反复重载、恰好耗尽、升级后继续开采、宏观资源账本、枯竭预估和真实配方扣料。普通精确模拟和同一时间的分段推进结果一致。宏观模式按自身样本/边界规则核算，检查的是每份实际产出对应的储量成本，不将其产量误称为和普通精确模式完全相同。

## 手机配方列表

真实浏览器复现通用弹窗 `min-block-size` 覆盖配方卡片 `min-height`，手机卡片从预期至少 84px 压到 44px；材料溢出卡片，负偏移的数量标签又被父容器裁切。

修复将卡片最小高度改为有足够选择器优先级的逻辑尺寸，并让目录行按内容高度排布；多种材料可以换行，数量标签留出边缘空间。图标随大字号放大，弹窗头部和搜索行也能随内容增长。搜索、关闭和点选行为继续使用原组件。

专项浏览器检查使用实际 `RecipeCatalogPicker` 和游戏样式，覆盖桌面 1280×820、手机竖屏 390×844、横屏 844×390，以及 80%/100%/125%/150%/200% 字号。检查全部卡片的标题/材料边界、图标与数量标签、横向溢出、列表末尾滚动、关闭入口和实际配方选择；完整应用回归另行验证。

## 补充的旧版浅色主题反馈

用户随后确认截图来自 1.0.0，因此先只读排查当前版本。真实合成工厂页面确认制造卡片、模式切换、锁定星球、节点与选择工具条已为浅色；保留了对应截图和计算样式。17 份样式文件中的深色常量不能直接视为现行缺陷，因为还存在主题覆盖。

实测仍发现两处小残留：制造列表视图外框为 `rgb(16,21,19)`，小地图折叠按钮为 `rgb(18,25,22)`。按原补充修复范围，只为这两个控件补齐浅色主题变量和悬停/焦点样式，不做整套主题重写，深色规则保持。新增浏览器检查覆盖真实应用的卡片/工具背景及两种主题切换；尚未把浏览器验证冒充 Windows 安装包实机验证。
