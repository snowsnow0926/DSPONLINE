## 最新这一批做成了什么

这一批补上了测试会话身份：桌面主进程和 Rust 能分别确认“这是哪一个实际测试目录、使用哪一份固定测试存档”。复制整个目录或替换 profile 后，原来的目录身份不能继续沿用。

测试还找出并修复了一个底层漏洞：原来只读取目录属性的句柄，无法阻止空目录被改名。已修正共享目录锁，并验证两个检查进程/持有者能核对相同身份，锁定期间不能替换目录或修改固定存档。

这解决的是继续接入实时计算所需的基础问题，本批尚未新增可量化的玩家提速。当前会话快照还没有变成持续运行许可，实际实时接管继续开发。[本批完整记录](./reviews/rust-windows-validation-session-2026-09-10.md)
