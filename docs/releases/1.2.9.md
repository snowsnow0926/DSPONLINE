# 1.2.9 网页与安卓正式发布

2026-09-11，北京时间。Role: release；用户明确授权发布与自主切换角色。

香港主站、新上海独立站和 Android stable 已发布 **1.2.9+0521eb63f179**。香港、上海 Web 分别于 **01:28:18 / 01:28:29** 切换，随后完成公网、设备、下载页修订及回退隔离验收。Windows 下载与两站 API 保持 1.2.6，数据库未迁移、恢复或改写。

入口：[香港主站](https://dsponline.cn/)、[客户端下载](https://download.dsponline.cn/)、[上一稳定版](https://dsponline.cn/canary/previous/)。上海保持独立 HTTP 入口及本机 API，仍禁止通过 HTTP 输入云账号密码。

## 玩家可见变化

- 网页与安卓共用保存、自动快照及模拟准备优化，减少重复复制、检查和扫描。沿用完整校验、备份、失败重试与存档恢复。
- 按住 WASD 移动画布，支持组合斜向移动。输入文字、弹窗、组合快捷键、失焦等情况下不会误移动；安卓外接键盘也可使用。
- 框选工具可启用“同时选中生产区域”；完整框入区域后，拖动选中节点即可一起移动边框。区域编辑条也可“选中区域与内部节点”，联动撤销、重做、保存与重开。
- 修复部分折叠节点连线端点，以及手机离线报告误弹退出提示、动画偏移和导航提交前关闭报告的问题。

GameState v47、envelope v2、cloud schema v8、SQLite layout v3 均不变。本版不接入 Web/Android Rust 核心，也不发布完整 Windows Rust 版本。香港既有历史人数展示补偿继续保留。

### 最终 APK 的直接升级与重开

新建匿名 `DSPidle129Release` 设备，离线、无窗口、静音、BelowNormal；没有复制个人 AVD 或玩家档。正式 1.2.8 创建工厂并通过“保存并返回”明确保存，再直接 `install -r` 最终 1.2.9：

- 包名和首次安装时间不变，主档时间及澄海 I 保留。
- 旧档的 3 个铁矿石、暂停状态及教程进度可见；升级后新增到 5 个，明确保存、force-stop、磁盘同步、冷重开后仍为 5 个。
- 再次进入运行状态后，50 秒离线结算成功提交，报告布局可用、确认后正常关闭，未误弹退出提示；铁矿石仍为 5。
- 全部自有模拟器已正常关闭。573.7 秒监护进程正常结束；Node 采样最低约 4.24 GiB、外部监护最低约 4.36 GiB，均未触及停止线。

首次 8 GiB 启动门槛未满足时未启动子进程。关闭 Vulkan、单设备配置改用 7.5 GiB 启动、3.5 GiB 提前正常退出、2 GiB 外部硬停止；模拟器将请求的 1,536 MiB 自动提高为 2,048 MiB，按实际值记录。一次 `am start -W` 在 10.269 秒返回等待超时，随后实际界面与存档进入通过；有一条 `UiAutomation` 工具异常。有限日志扫描未发现 IndexedDB 损坏/重建或 renderer-gone 标记。

设备证据不是实体手机测试，也没有导出原生私有 IndexedDB 做完整状态逐字段比对。此前旧匿名 AVD 的 LevelDB 损坏记录保留，最终成功直接升级不能证明此前损坏原因。实体手机、温度、耗电与长时间后台未验证，没有继承历史版本的豁免。
