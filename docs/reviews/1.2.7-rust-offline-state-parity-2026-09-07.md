## 普通尾段的严格资格

[父流程](../../native/dsp-native-core/src/pure_idle.rs) 保留真实 30 秒 Exact 校准和原普通物料证书。在物料宏写入前准备额外的 flow、history 和无出口时钟证明；任何证明失败都返回 unsupported，丢弃整个候选。不能先对外推状态补跑 Exact，再把重叠时间算作已正确完成。

[Flow 模块](../../native/dsp-native-core/src/pure_idle/offline_flow.rs) 只处理已获证、未触及容量或矿量边界的窄普通链：铁矿源、铁块冶炼、非燃料风力供电及纯上传的二级量子站。活动配方限定 `iron_ingot`，正生产项限定 `iron_ore` / `iron_ingot`；铁块生产要求 `smelt_iron` 同时存在于已完成和已发奖任务记录。已有但与该产线无关的未完成任务不能仅凭短探针被解释为新获支持的任务系统。

量子站须没有需求槽、传统运输工具、活动航线或模式切换，上传物品与实际缓存闭合。传送带端点须无歧义；共享输入、分流、循环或未知运行字段均不借用此资格。科研、手工、施工、戴森发射、外贸、轨道合同、探索任务、空间站自动工作、活动建设计时及启用的时间加速等独立写入者不进入本阶段的新证明范围。完整资格仍以最终源码和差分矩阵为准。

物料投影后，原 campaign 同步及轨道站资格同步还须在局部副本上完全不写入；出现新完成、奖励或解锁立即拒绝，副本不发布。限定范围内产量单调增加，其余任务指标和库存托盘固定，因此端点无写入检查排除尾段跨任务阈值。建设活动显式拒绝，戴森同时扫描实际各轨道的帆存量，不依靠单个聚合字段推断生命周期停止。

额外探针在私有状态上执行 **30 次真实的一秒 Exact**，与原校准分开计数。每一秒的物理实体、输入输出、机器进度和普通遥测均须与前缀保持相同；仅按原证书解释的生产累计、量子库存和有限矿扣账可以归一化。它不是只检查十秒末端相同的周期猜测。因此非整十秒尾段不能在错误的物理相位上套用平均产量。

传送带逐秒累计增量必须稳定且非负，最终计数先校验整数溢出。量子 `runtimeFlow` 的完整已知结构、上传/下载项、刷新边界和十秒内相位通过三个真实周期核对；不以最后一帧速率乘总时长代替累计传输，也不只改一个时间戳隐藏其余字段差异。证明绑定源 canonical、revision、检查点身份、不可变 catalog 实例和请求尾长，不能跨存档或跨目录复用。

## 历史与时钟

[History 模块](../../native/dsp-native-core/src/pure_idle/offline_history.rs) 复用同一组 30 次真实探针的末秒历史样本，不再独立模拟另一套工厂。首十秒保留实际样本中的旧诊断缓存；第二、第三个十秒周期必须逐相位完全一致，才允许重放后续序列。首周期未刷新时的旧库存或效率不能被稳定末值提前覆盖。

每个未来样本重新通过[原历史边界函数与 append/compact 实现](../../native/dsp-native-core/src/production_history.rs)，保留原有历史、采样时长、十秒诊断刷新、加权合并顺序，以及 1 / 10 / 60 秒分辨率和保留窗口。小数时钟造成的实际浮点采样时长也按原记录器产生，不能一律写成 `1`。未来刷新相位与证明不符时拒绝。历史先在局部数组完整构建，成功后只写候选的 `productionHistory`、`historyRecordedAt`，并使旧的私有历史投影缓存失效。

[共享时钟入口](../../native/dsp-native-core/src/simulation.rs) 使用真正 Exact 步骤调用的 `exact_elapsed_after_step`，避免另写四位小数规则。无新增出口证明在最多八小时范围内逐秒重放标量窗口，保留首个窗口已有 amount，之后才进入零新增出口窗口；返回经过证明的最终 elapsed 供父流程提交。循环不扫描实体、不在每步写入持久 JSON。

窗口证明只接受无物理出口建筑、明确的 `building` 模式，或 `legacy-network` 且显式关闭自动派发。未知模式或可能继续派发的 legacy 状态拒绝。一般宏的源时钟、量子边界和历史相位还必须同时通过各自更窄的证明；单独窗口 helper 接受某个大时钟不代表整个宏已经支持该输入。已有 Exact 回退继续保留其真实 elapsed，不再被父流程的一次浮点加法覆盖。

## 预算与隔离

| 边界 | 当前实现限制 |
| --- | --- |
| 新宏尾段 / 原请求 | 尾段为 1–28,800 个整数秒；组合后的无出口路径要求原请求为整数且不超过八小时 |
| 额外真实探针 | `30 × max(1, 实体数 + 传送带数) ≤ 60,000`，在复制探针状态前检查 |
| 探针内存 | 原始记录不超过 8 MiB、估算运行内存不超过 32 MiB；探针推进后继续复查 |
| 共享历史样本 | 30 个真实样本序列化累计不超过 2 MiB，不保留 30 份完整 CoreState |
| 新宏源时钟 | 四位小数规范起点，逐秒时钟与量子相位一致，且不超过 1,000,000,000 秒；异常或精度漂移拒绝 |
| 累计流量 | 非负整数，投影后不超过安全整数上限，所有乘加先检查 |
| 既有触界 Exact 回退 | 原请求不超过八小时，`ceil(请求秒数) × max(1, 实体数 + 传送带数) ≤ 4,000,000`；超预算拒绝 |

本阶段仍存在候选复制、探针状态复制、规范签名构建、历史样本复制及逐秒压缩。历史重建的目的在于避免每秒扫描整厂，**不声明零拷贝、O(1) 历史重建或所有边界保留宏速度**。窗口标量重放与历史压缩均计入端到端性能测量。

物料、元数据、历史及窗口全部在私有 candidate 上完成，最终总账校验通过后才安装源状态。预算、时钟、证明绑定、未知字段、缓冲漂移或溢出失败均须保留源 revision、完整状态及持久检查点。取消、失败和未获资格不能被统计为完成的离线结算。

本阶段输入只使用公共目录和合成夹具，**未执行私有玩家存档的读取、写入、导入或上传**。没有以真实终局档作本轮 Rust 收益样本。实现位于原生 Rust 路径，不能据此宣称网页版、安卓版或三端帧率提升。

- `flow-focused-v2.log`：后续筛选仍记录了两个 JSON 数字表示差异，分别为累计传输 `61` / `61.0` 和量子边界 `75` / `75.0`；最终修复与复验状态待主任务填写。规范哈希相同与原始 Value/字节相同须分别说明。
