# 1.1.3 Web 云连接热修记录

状态：已完成香港与上海 Web-only 稳定热修；API、数据库、下载页、Android/Windows stable 未切换。

## 根因

1.1.3 的生产 Web 入口误用了原生平台构建后的共享 `dist`。入口 JavaScript 被静态折叠为 `cloudApiBase() -> null`、`isWebCloudRuntime() -> false`，浏览器因此把云请求判定为“原生应用未配置云服务地址”，即使香港 API `/api/health` 与 `/api/ready` 均正常，也会显示“云端离线”。

本修复在构建层固定 `VITE_APP_PLATFORM=web`，产出 `build-platform.json`，并在发布前强制校验平台元数据、版本/build 标记和入口资源，防止再次把 Android/Desktop `dist` 当作 Web 包。启动预算按真实 Web 闭包基线增加 1 KiB，未放宽功能门禁。
