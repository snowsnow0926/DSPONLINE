# 从 1.3.4 发布到现在的性能报告

日期：2026-10-29；开发角色，依据既有测试汇总。性能循环目标查询结果为 paused，本次报告未恢复目标、未启动新压测或发布。

**能确认的新成果主要是制造计算变快，网页进出等待只小幅改善。最新内存方案在守恒模式中有明显下降，但退出卡顿和产率复制仍不理想，尚未整体验收。新增优化均未发布。**

## 统计起点

从已发布香港 Web **1.3.4 / `61fb10311cb9`** 起算。此前蓝图八倍扩容、进入最长画面间隔减少 89.3%、峰值减少 23.9% 等已经包含在 1.3.4 内，本报告不重复计入。[发布记录](../releases/1.3.4.md)。

当前已验收本地开发运行是 **`8c54cd02fd93`**；最新存档交接候选 **`3ffa237dabac`** 仍待改进及完整资格。这是开发状态，不是新的线上版本。

## 已通过验收的阶段成果

制造测试使用同一原库存终局工厂，固定推进 240 模拟秒。下列数值是各自对照组的中位数，耗时减少才是百分比含义；不是整个游戏的帧率提升。

| 场景与阶段 | 优化前 | 优化后 | 已验证变化 |
| --- | ---: | ---: | ---: |
| 第一轮递归制造，1.3.4 → 13e808 | 3.894 秒 | 3.468 秒 | 计算耗时少 10.94% |
| 后续制造/电网组合，13e808 → 8c54 | 3.447 秒 | 3.145 秒 | 计算耗时再少 8.78% |
| 后续组合，托盘材料充足的压力条件 | 1.447 秒 | 1.239 秒 | 计算耗时少 14.34% |
| 后续组合，量子供料充足的压力条件 | 0.645 秒 | 0.624 秒 | 计算耗时少 3.37% |
| 第一轮实际网页退出保存 | 10.744 秒 | 10.589 秒 | 少 155 ms /1.44% |
| 第一轮实际网页渲染进程峰值 | 4.168 GB | 4.021 GB | 少约 147 MB /3.53% |

前后两轮的对照基线不同，时间也来自不同批次，**不能把 10.94% 和 8.78% 相加成全游戏累计提升**。目前没有正式发布 1.3.4 到最新最终开发版的同轮完整直接对照，因此不提供一个未经验证的累计总百分比。后续组合的实际网页峰值约 4.539→4.533 GB，按基本持平处理，没有证实进一步下降；第一轮的 3.53% 也不充当如今所有场景的保证。

对玩家的意义是：原料够时少走无用的递归分支，制造批次少重复规划，量子需求和电网少重复扫描。高级配方优先、量子取料、材料守恒、制造加速规则均保留。托盘和量子充足两项是在只读副本中补料形成的压力条件，不当作玩家自然库存。

来源：[第一轮递归制造与正式 1.3.4 对照](./2026-10-28-web-stocked-recipe-inputs.md)、[后续制造/电网组合完整验收](./2026-10-29-web-construction-power-qualification.md)。

## 最新内存试验：有局部收益，暂不算整体验收成果

最新候选恢复已接受计算源码，只独立验证存档交接。两种模式各旧/新/新/旧，共 **8 个新浏览器、64 个完整系统采样点**，每页 40 秒，均实际发送停止快照；无堆/CPU 剖析和强制 GC。全部原值、高值和查询时间保留。对照是已接受本地 8c54，**不是直接与线上 1.3.4 比较**。

| 同档最新对照 | 旧开发版 | 新候选 | 结果 |
| --- | ---: | ---: | ---: |
| 守恒：渲染进程峰值 | 4.326 GB | 3.997 GB | 少约 329 MB /7.59% |
| 守恒：停止后约 3 秒工作集 | 2.509 GB | 1.956 GB | 少约 553 MB /22.03% |
| 守恒：停止最长帧间隔 | 94.95 ms | 113.70 ms | 增加 19.75%，需处理 |
| 产率复制：渲染进程峰值 | 4.237 GB | 4.294 GB | 增加 1.35%，没有稳定改善 |
| 产率复制：进入等待 | 8.817 秒 | 8.955 秒 | 增加约 138 ms /1.56% |

守恒峰值旧范围 **4.278–4.374 GB**、新 **3.885–4.110 GB**；复制新范围 **3.945–4.643 GB**，保留高值，不能只挑较低一次。停止最长帧是每页观测窗口的最差画面间隔，不是整体 FPS；每变体每模式只有两次，不作统计置信或长期无泄漏承诺。30/60 秒占用基本相当，不能替代瞬态目标。

因此当前方案仍作为待改进候选，不能把 7.59% 或 22.03% 写成整个游戏已经省下的内存。先前约快 8.4% 的守恒组合，因为两模式峰值多 5.8%–9.9% 而被拆出，同样不计成果。[最新全部数值与资格边界](./evidence/2026-10-29-io-isolation-natural.json)、[前一组合拒收记录](./2026-10-29-owned-decode-buffer.md)。

## 验证程度与还没解决的部分

- 已验收 8c54：完整单元 **3,795 通过/38 跳过**、Chromium **524/34**、PWA **1/0**、恢复 **21/22**，最终 0 失败、0 flaky；17 次真实样本完整状态/正文对照一致。
- 最新 3ffa：**83 项针对性与类型通过**，构建/预算/原生检查通过，198 文件/16 Worker 冻结复核；8 次 raw/gzip 大档快照全文逐字节一致、原输入和原样本摘要保持。该八次是辅助函数组件检查，不冒充实际编译 Worker 的中断恢复资格；组件前置 GC 不算自然网页收益。
- 最新候选尚缺相应完整单元、浏览器/PWA/恢复及必要真实大档中断恢复资格；旧候选的 3,916 单元等不能借作本候选通过数。
- Rust 流式 SHA 原型已通过组件正确性检查，尚未接入游戏、没有浏览器性能结论，不计优化成果。

最近同档观测中，产率复制进入仍约 **9 秒**、退出约 **10.6 秒**，守恒准备仍约 **30 秒**。大档还需要约 4 GB 量级瞬态内存，低内存设备和长期挂机尚未完成资格。离线结算尚无可计入本报告的终局整段累计新提速百分比，不能认定三项功能都已全面丝滑。

后续开发优先处理退出卡顿、复制模式峰值波动和守恒初始化等待，再做整体组合对照及完整回归。所有数字均来自同一原 **105 MiB 级存档的既有测试副本**；展开副本不是玩家存档增长。真实存档、自动备份停用设置及已发布系统未被本次报告修改。
