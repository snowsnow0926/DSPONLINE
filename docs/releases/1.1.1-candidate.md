## Implemented

- 合同规范化以 history/settledIds 为权威，过滤同 ID 的已结算报价，同时保留历史、奖励和防重复领奖边界。
- 同一任务日不再重新生成已结算的确定性报价，下一任务日仍生成新报价。
- API 只接受 exact identity + settled fence 的 1.1.0 遗留重复报价；伪造奖励、缺失 fence 和其他碰撞继续拒绝。
- Persistence Worker 可为同 owner/token 的过期 writer lease 安全续租；任何 owner/token 变化继续拒绝。
- proof 后的同页 legacy/lifecycle 保存仅在完整 durable proof 和相同 fence 下 rebase，真实接管仍保留双方版本。
- React effect cleanup 不再绕过 primary persistence lifecycle；替换 effect/StrictMode cleanup 被 generation 取消，纯挂机持有时间线时不注入 cleanup 写入。
- 当前发布说明升级至 1.1.1，并保留 1.1.0 RuntimeWorld 2.0 历史条目。
