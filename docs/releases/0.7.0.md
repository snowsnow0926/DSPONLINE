## 本次范围

- 行星与星际物流站支持供给端主动送货和需求端主动取货；航线保存载具所属站，按所属站处理占用、返航、供电、翘曲器扣除与退款。
- 每颗行星独立记忆 React Flow 中心与缩放；书签、设备和线路定位仍可覆盖普通恢复视角。
- 增加深色、亮色和跟随系统主题，覆盖桌面、画布、线路标签、工作区、科技树、统计、原生表单和新版手机壳。
- 建筑制造中心递归加工缺少的可制造中间材料，按材料 0.1 秒/件、建筑成品 5 秒/个推进，并显示阶段、进度、预计时间和缺料。
- 移除分拣器 Mk.I/Mk.II/Mk.III 的施工、制造、科技和图鉴入口；旧库存等量退为对应传送带，旧线路字段归一为传送带等级。
- 科技树增加标准/精简布局；设置、星图、科技、资料库、统计、银河、任务等主入口再次点击会关闭当前工作区，蓝图、戴森、网络与新版手机导航遵循同一规则。
- 输入、输出、燃料、仓储、物流槽、载具和翘曲器容量随建筑堆叠增长；减少堆叠保留超额库存并暂停继续输入。
- 物流站后续线路复用同物品槽或依次使用第一个空槽，不覆盖手动配置；空槽已满、物品冲突和方向非法返回明确原因。
- 0.7.0 更新公告首次进入显示一次，并可从设置重新打开；已读偏好不进入 GameState 或云存档。
