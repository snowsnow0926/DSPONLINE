# 1.2.7 网页与安卓正式发布记录

日期：2026-09-08。Role: release。最终线上读回 09:59 UTC，公开下载检查完成 10:00 UTC（北京时间 18:00）。

香港主站、新上海独立站 Web、Android stable 及下载页已发布 1.2.7。两地 API 与 Windows stable 保持 1.2.6；Rust 跨端接入留待后续。用户已明确授权两站独立发布、安卓/下载更新、提交及自主切换角色。本记录区分实际通过项、条件跳过和未完成的验证，不复用旧版本豁免。

## 玩家可见变化

- 停止挂机期间阻止启动恢复重复认领；结算完成但保存失败时，本页保留已验证结果用于重试保存，避免重复计算。
- 挂机界面可独立导出私人恢复诊断数据；失败和导出都保留主档及恢复日志。离线报告延后展示，避免遮挡或禁用挂机控件。
- 网页与安卓采用共享的保存、导入和离线准备优化。完整模拟状态分批编码到原有 UTF-8 transfer，降低完整 JSON 中间对象峰值，所有字段及 JSON 语义保留。
- 安卓启动有界等待已观测到的旧写入租约自然到期，不清缓存、不强抢活跃写入者。

GameState v47、envelope v2、cloud schema v8、SQLite layout v3 均不变。实时模拟仍为 JS 权威，不能把此前 Windows 开发样本的性能百分比当作网页或安卓的实测收益。私有云档副本的构造测试也不等于已找回玩家当前浏览器内那次挂机日志；玩家应保留浏览器数据后刷新更新，若仍失败可导出恢复数据继续排查。

## 回退边界

1. 香港若需回退根 Web，先恢复上述精确 Nginx snippet 备份，校验 SHA、nginx -t/reload，然后通过维护入口显式指定 `web-1.2.6-df828869e276`，保持 API 1.2.6。仅撤销 fallback 时只恢复 snippet。
2. 新上海 Web 回退同样只显式指定旧 Web 目录；继续使用新机合同，不回到停写旧机，不恢复数据库，不移除迁移恢复配置。
3. 下载页单独回到 `download-site-1.2.6-df828869e276`；不连带切换 Web/API。已安装 Android 不能靠改 feed 安全降级，如需补救应构建更高 versionCode 的修复包。

不得使用 `--rollback-last` 代替上述目标，也不得把旧数据库快照恢复到仍有新写入的服务。后续 Git 文档和测试夹具提交不改变冻结 runtime 或线上制品。
