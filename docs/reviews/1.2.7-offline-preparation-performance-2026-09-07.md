## 实现与约束

1. [数值校验与保守预览](../../src/game/offlineApproximation.ts)：深度优先校验改用一个局部路径栈，`try/finally` 保证退栈；只在发现错误时生成文本。复用只读的十进制字段集合，取消逐节点路径数组和临时 Set。遍历顺序、循环去重、非法数值/字符串判定及大派生功率值例外保持不变。会保留路径的 `captureAffineSnapshot` 没有使用可变路径。
2. 保守预览删除随后会被精确前缀覆盖的提前全档复制；仍创建隔离候选，异常回退重新从原始状态复制，精确前缀和最终守恒检查不变。只读 `captureProjection` 的两处外围复制也已去掉。
3. [提示内复杂度绑定](../../src/game/offlineComplexityBinding.ts) 与 [StartMenu](../../src/components/StartMenu.tsx)：复用本次不可变加载提示已计算的复杂度。绑定加载包装对象、状态引用、存档时间、离线时长、恢复引用/来源和原生恢复候选；任一来源或边界变化即回到原分类。没有给可变运行态建立长期缓存，没有改阈值、截止时间或玩家选择流程。
4. [Node 对照脚本](../../scripts/benchmark-private-offline-preparation.mjs) 固定基线所有源码依赖；[实包脚本](../../scripts/benchmark-desktop-private-save.mjs) 增加真实决定弹窗与取消后的持久边界验收。真实档不录屏、不抓 trace、不输出内容。

代码提交：`e6eaeae5`（提示复用）、`447c9fd0`（校验与复制）、`2b8434ac`（公共目录资格调查）、`1c1b8015`（性能驱动）；`80b4976d`、`5ef2e7af` 仅修正桌面测试启动弹窗处理。后续文档提交不改变运行包身份。

## Rust 长时资格：NOT_QUALIFIED

[公共目录测试](../../src/game/nativeOfflinePublicCatalog.test.ts) 使用 [公开夹具](../../tests/fixtures/rust-offline-performance.ts)：110 实体、2 传送带、100 台真实风机，采矿→冶炼→二级量子上传链，逐秒 JS 精确模拟为对照。本轮没有修改 Rust 算法。

| 场景 | 离线秒 | Rust 宏累计铁块 | JS 精确累计铁块 | 物料等价 |
| --- | ---: | ---: | ---: | --- |
| 无限矿 | 600 | 629 | 629 | 通过 |
| 无限矿 | 28,800 | 28,829 | 28,829 | 通过 |
| 有限矿 2,000 | 600 | 629 | 629 | 通过 |
| 有限矿 2,000 | 28,800 | 2,029 | 2,030 | 未通过 |
| 量子容量 10,000，预填 9,950 | 600 | 79 | 629 | 未通过 |
| 同容量边界 | 28,800 | 79 | 2,199 | 未通过 |

累计值包含 30 秒预热。六例守恒、有限矿扣账及容量安全检查通过，仅说明没有发现物料凭空增加或越界；**物料等价 3/6，完整状态等价 0/6**，不能把绿色安全测试解释为资格通过。Native Exact 三个 10 分钟样本完整规范状态与 JS 相同；另一次 8 小时 Exact 探索也相同，耗时约 159 秒。

阻断点与下一阶段最小范围：

- 容量满后宏候选冻结，JS 仍填充塔和炉的实际缓冲，10 分钟 / 8 小时少 550 / 2,120 铁块。应证明剩余缓冲与生产尾段，不扩大库存容量。
- 有限矿耗尽后，已有炉内 1 单位矿石没有完成冶炼。应结算已存在的输入和加工进度，不增加矿源产出。
- 所有样本 `endgame.exportWindowStartedAt` 停在 51，而 JS 为 621 / 28,821。须按公共引擎规则推进窗口及关联计数，覆盖跨窗口和恢复，不能只改时间戳。
- belts、productionHistory、historyRecordedAt、quantumLogisticsNetwork、endgame 等完整状态差异仍需解释或修复；耗尽/容量场景还涉及实体、累计生产及统计/电网字段。

长例以 `DSP_RUN_NATIVE_CORE_LONG_DIFFERENTIAL=1` 显式运行；默认完整单元套件跳过三例。测试没有把错误少产数锁为理想行为。Host 对 31 / 600 / 28,800 秒的自动采用仍拒绝、源规范状态不变、没有 candidateSummary；实时 `authorityEligible=false` 不变。

## 调查中未接入的方向

- 直接消费已拥有记录的会话优化：冻结原版合成对照，大图会话创建中位约 32.29 → 27.55 ms，但小图 5.04 → 6.05 ms 且三对均变慢。净收益有限，已撤回全部 engine/Worker 实验修改。
- 真档 conservative 的触发项是序列化估算 236,096,984 字节超过 128 MiB；估算峰值约 3.287 GiB，尚未到 4 GiB。磁盘状态约 102.65 MiB，迁移运行态约 191.54 MiB，差额全部来自实体和传送带正规化。不能用磁盘尺寸替代运行态估算来绕过保护，亦未删除引擎所需字段。
