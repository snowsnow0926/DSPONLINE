# Windows Rust 开发进度｜2026-09-10

完整 Windows Rust Goal 持续进行，仍是开发版。**这一轮连接了实际桌面运行控制器与真实 Rust 进程，找出并修复两处问题；正式玩家实时接管尚未开放，没有发布。**

## 这次实际做成了什么

1. **修复合法建造被拒绝。** JavaScript 将整数坐标写成 `4000`，Rust 校验时重建为 `4000.0`，严格 JSON 比较误判不一致。现在验证坐标为有限数值后保留原数字表示；非法坐标和额外字段仍拒绝，库存不会被错误扣除。
2. **修复正常退出变成强制结束。** 桌面连接以前收到关闭回复就立即 kill Rust；现在在原五秒期限内等待进程真正关闭，超时才终止并确认结果。并发停止共用一次请求；无法确认终止时明确报错并禁止原连接重新启动。
3. **完成连续操作测试。** 建造、重试同一次建造、推进生产、暂停一小时、恢复、完整导出、正常退出与重开，以及“建造已落盘但确认丢失、进程中断后重开”，均与独立 JavaScript 引擎的完整状态一致。两次建造只扣两份库存，暂停的一小时不计入模拟，实际推进七秒。

游戏回复来自独立 Rust 进程。桌面 runtime、连接和会话注册器使用实际实现，普通 Host 与测试进程共用 `rpc.rs` 的请求处理、持久化和启动恢复代码。

**限定范围：接管许可使用 Rust cfg(test) 合成授权，证据为 TEST_ONLY。** 它不能授予正式玩家权限，尚未覆盖 Electron 界面交接、可信资格或全部玩法，也没有新增可报告的性能提升百分比。
