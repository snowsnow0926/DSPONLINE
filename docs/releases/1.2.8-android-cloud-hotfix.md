# Android 1.2.8 云连接修复发布记录

2026-09-09 00:35（Asia/Shanghai），已按用户修复及切换角色授权发布到新上海下载站和 Android stable。香港/上海 Web、API、数据库与 Windows 安装包不在本次切换范围。

## 故障与修复

正式 Android 1.2.7 APK 漏配云 API、更新清单和公开账号 origin。原始包可复现“原生应用未配置云服务地址”，没有发出 API 请求；服务端 TLS、Origin 和健康探针正常。详见 [故障调查](./android-1.2.7-cloud-unavailable-2026-09-09.md)。

1.2.8 显式配置 `https://dsponline.cn/api`、`https://dsponline.cn/downloads/android/stable.json` 和 `https://dsponline.cn`。受保护正式签名入口启用 official 构建检查，漏配、HTTP、带凭据/查询/片段的地址均拒绝构建；完成后检查编译 JS 包含全部配置地址。社区离线构建保持可用，桌面构建不会继承 Android 地址。

保留包名 `cn.dsponline.network`、`https://localhost` 存储 origin、CapacitorHttp、长期签名及存档格式。源码基于公开 1.2.7 发布线，包含用户批准的香港累计人数历史补偿 3,700（2026-08-14 至 2026-09-07），只在显示层计算一次。
