3. **最新完整游戏检查通过。** 游戏 **3,178 通过、39 条件跳过、0 失败**，其中实际 Rust 对照 **50 通过、1 长测跳过**；类型、Web 构建及三项门禁通过。新增边界测试覆盖长文本、中文、emoji、孤立代理项和二进制数字。Rust 和正常 Host 未改，沿用上一批核心 **1,115/5 条件忽略**、Host **256/1 驱动忽略**、Native 接口 **750/1 条件跳过**及严格检查的证据。

上面两个收益来自不同环节，**不能把 4.99% 和 9.34% 相加当作整款游戏提速**，也没有新增帧率或全进程内存收益结论。

**最新 57ce 包已构建并校验，终局完整验收仍失败。** 75 项制品、78 个文件通过。真实 9 秒结算后约 90.49 秒进入运营中心，随后测试独立读取存档时连接关闭；两次正常退出，原始存档未变。尚未完成完整落盘状态和两次重开的验证，不能称为可发布完整版本。已准备只读后台诊断；因可用内存低于 6 GiB 启动余量而推迟，没有启动游戏。保留内存保护，云端新源码检查继续进行。

此前 629 冻结包的 75 项制品、78 个文件校验通过，但 **9 秒终局结算的完整入口仍超原 90 秒**。这次实际请求约 45.36 秒，截止前只创建一个模拟 Worker，菜单和失败后的关闭都正常；成功持久保存与两次重开没有执行。

一次采样实际结算 8 秒、约 81 秒进入运营中心，随后在测试读取持久存档时失败，不能计作同一 9 秒场景通过。后一次实际结算 13 秒的诊断取得了 CPU 热点，仍未通过入口；这些样本各自保留。最新缓冲优化已进 629 冻结包，但 v14 的 9 秒完整入口仍失败。

863 的 Linux 单元、构建和 Server/Ops/Native 通过，完整浏览器仍 **29 项失败、16 项重试后通过**；两项启动顺序与精确堆叠连线均首轮通过。863 Windows 云端的 Rust/Native 通过，完整游戏有 1 项内存采样节奏失败。采样器会把读取时间再叠加固定睡眠；现已改为只等待剩余周期，旧反例失败，修复后两项核心测试各三轮全部通过，完整文件 8/1 条件跳过、策略工具和类型通过。原时间戳、采样门槛及用例时限均保留；仍须新云端验证。云端总数波动不等于具体问题已经修复。

最新 57ce 云端单元、构建、Server/Ops/Native 及独立 Windows 完整检查通过；Windows 游戏 3,180/39 条件跳过，采样器复验也通过。完整浏览器仍有 28 项失败、24 项重试后通过；新增四项保存/迁移/快照均首轮通过。下一轮减少同一云端机器的浏览器争用，保持完整测试及原门槛。另已补[正式资格的实施方案](./rust/windows-qualification-carrier.md)，平台验证器、签发与实际接管仍未完成。
