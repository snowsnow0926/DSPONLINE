## 完成的含义

保留现有 Electron/React 界面，受支持游戏模拟和持久操作由 Rust 单独掌握完整状态。玩家可以正常建造、运输、科研、操作终局系统、离线结算、保存和恢复；结果与原规则一致，并在大工厂完整流程和内存上取得可复现的收益。最终交付与源码、Host、桌面包完全对应的验收记录和可发布候选。

不要求把按钮和界面代码全部改写成 Rust。Web/Android Rust 接入仍属后续独立范围；完整 Windows 开发目标也不等于立即修改生产服务。
