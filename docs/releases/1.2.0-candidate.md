## 候选内容

1. Windows 私有增量存档：内容寻址压缩区块、双 superblock、连续 WAL、原子 generation、验证恢复和有界 IPC。
2. Windows 独立 Rust 模拟核心：邀请 Beta 默认关闭，JavaScript 保持权威；支持影子检查点、命令镜像、规范哈希、投影和无静默回档恢复状态机。
3. 原生精确领域：采矿、普通/增产生产、电力、线路、行星与星际物流、量子网络、建筑制造、戴森、空间站、进度、速通和内容包目录边界。
4. 保守时间扭曲 P0：删除一秒探针累计量长窗复制；火箭、太阳帆、结构/壳面、出口和合同加入事务性守恒门禁。
5. 服务端排行榜纵深防护：支持 v46/v47 相邻 revision 的火箭/太阳帆来源检查；异常只进入人工复核并保留上一份有效成绩。
6. 1.2.0 中英文当前更新说明、历史 1.1.9 记录和 E2E 版本夹具同步。

## 兼容边界

- GameState v47、save envelope v2、cloud schema v8、SQLite layout v3 不变。
- Windows 私有原生文件不是云协议、Mod API 或跨平台存档；公开导入/导出继续是 v47 JSON。
- 不自动修改历史戴森数据，不修复真实玩家存档，不把排行榜异常当作自动封禁依据。
- `authorityEligible=false` 保持硬门禁；1.2.0 不宣称默认原生权威。

## Release Agent 必须完成

- 从 manifest 绑定的 clean commit 复验依赖、完整门禁和制品哈希。
- 按授权目标执行正式 Windows/Android 签名、安装和覆盖升级；未签名包只能作为诊断制品。
- 真实 Linux/systemd/Nginx、两地数据库备份、preflight、原子切换、health/ready、公网 PWA/Range/完整哈希和观察期。
- Windows 低配/主流硬件及至少 Windows 10/11 的 Electron 长跑；不得把本机单次 benchmark 替代为多硬件或 24 小时证明。

任何门禁失败都保持现网不变并作废该候选；不得放宽守恒、恢复或签名门禁来换取发布。
