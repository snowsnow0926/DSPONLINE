## 1. 交接结论

玩家提供的导出档能够稳定复现 `pure-idle-macro-v3` 的风险：三段校准虽然形成了原有仿射合同，但最后两段逐物品产量速率并不稳定；终局极限 UI 模式又关闭了周期影子校验。浏览器或操作系统整夜休眠且没有送达 `visibilitychange/pagehide` 时，恢复编排可能把同一份已过期合同用于全部未推进墙钟区间。

候选升级为 `pure-idle-macro-v4`。校准会检查最后两段逐物品累计产量增量，最大相对漂移超过 20% 时不再使用该仿射合同，而是按普通权威模拟分段精确推进。单次高倍率精确推进最多接受 60 秒墙钟；浏览器休眠或计时器长时间无进度时，以最后已提交结算边界建立隐式后台检查点，剩余尾段交给现有普通离线流程。终局极限模式现在与普通 UI 模式一样保留周期影子校验。

本修复没有删除缓存、跳过已经成功生产的物资、补发物资或修改矿脉；不稳定路径直接复用普通模拟，因此矿脉扣除、矿机输出、传送带、物流、量子库存和托盘仍由同一引擎提交。

## 4. 存档结构与迁移

没有修改 `GameState v46`、envelope v2、本地槽位、云 schema v7、SQLite layout v2、速通字段或排行榜协议，因此玩家主档、导出文件、云档和模式隔离均不需要迁移。

仅 Worker/IndexedDB 纯挂机恢复摘要新增运行时字段：

```text
settlementMode = affine | bounded-exact | conservative
algorithmVersion = pure-idle-macro-v4
```

该摘要不属于玩家存档或云 payload。旧 v1/v2/v3 恢复记录仍按现有 schema 读取；缺少 `settlementMode` 时先按 60 秒有界路径处理，随后从原始合法检查点用 v4 重新校准。迁移幂等，不复制主档、不覆盖槽位，也不要求删除 IndexedDB。

## 5. 计时、恢复与幂等修复

- 使用恢复记录的 `settledWallSeconds` 与摘要中的已提交边界取最大值，作为唯一已结算游标。
- 若总墙钟与该游标之间出现超过安全阈值的空洞，且没有显式后台时间戳，则把最后已提交边界视为隐式后台开始点。
- 稳定仿射路径沿用既有 300 秒后台高倍率宽限；不稳定或待重校准路径最多再推进 60 秒高倍率精确段。
- 高倍率段与普通离线尾段严格拆成不重叠区间；停止、定时 tick、页面恢复均复用同一后台恢复单飞锁、结算 ID、冻结边界和保存读回门禁。
- 同一目标再次调用不会推进状态；超过 60 秒的单次分段精确请求会在变更候选前拒绝，并要求编排层转交普通离线尾段。
- `markPureIdleBackground` 将历史后台边界与当前租约更新时间分开，避免用旧时间戳创建已过期租约。

## 6. 资源结算修复

- 校准额外保留四份小型 `totalProduced` 计数表，不复制四份完整 `GameState`。
- 最大产量速率漂移超过 20% 时，不再外推不稳定合同。
- 有界精确路径调用 `advanceExactSimulationWindow`，复用普通引擎的供电、矿脉扣除、输出容量、传送带、建筑缓存、传统/量子物流、托盘和科研规则。
- 合成容量边界用例验证：矿机输出与累计产量一致，除运行时生产历史采样粒度外的完整状态哈希与普通精确路径一致；重复目标状态哈希不变。
- 既有 1x/4x/8x/12x、供电不足、输出满/近满、堵带、有限/无限矿脉和 30 天边界测试继续通过。

## 9. 性能影响

- 稳定工厂只增加四份逐物品累计计数浅副本及一次 O(物品种类数) 漂移计算；不会增加主线程完整存档复制。
- 不稳定工厂会增加 Worker 精确模拟成本，换取缓存、物流和矿脉严格一致；单次墙钟目标硬限 60 秒，长时间休眠不会精确重放整夜。
- 玩家 2.15 MB 档的五窗口专项和 9 小时普通离线重放在 20 秒左右完成。
- 23 MB 终局档若持续可见且长期被判为不稳定，30 秒墙钟 × 高倍率的精确段仍可能接近 Worker 30 秒操作预算；没有低配 Windows、Android 真机或该 23 MB 档的 v4 持续整夜实测，不能承诺所有设备无积压。

## 10. 未解决风险

- 普通离线尾段仍沿用已有 `fast-30s-v2` 误差与玩家决策策略；本修复没有扩大阈值，也没有重写该算法。玩家档 9 小时重放的现有非关键最大估计误差约 98.62%，因此不能把普通离线尾段描述为全状态精确。
- 浏览器被系统挂起时，高倍率纯挂机不能在后台无限保留；稳定路径最多保留原有 5 分钟，不稳定路径保留更短的有界精确段。这是防止过期合同和超时的安全取舍，UI 会明确提示已切换普通离线尾段。
- 生产历史采样桶会随精确分段粒度不同而不同；该历史在持久投影中可重建，玩法状态、缓存、在途物资和累计产量对照保持一致。
- 本机没有物理 Android、低配 Windows、浏览器整夜真实休眠或多设备云恢复证据。
- 当前玩家档本身不包含足以自动解除历史排行榜限制的新证据；如需人工恢复，必须另开治理任务。
