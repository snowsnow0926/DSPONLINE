## 产品变更及实际触发场景

1. Windows 原生侧车先核验公开主档与清单，只在基础校验和匹配时逐块读取。过期检查点只读取一条清单，避免搬运整份无用旧工厂。
2. 原生侧车与 IndexedDB 使用相同的异步重建规则，保留区块校验和、字节长度、版本、模式、公开 envelope 校验和，以及每次 IPC 的 generation / rootHash 绑定。
3. Rust 单记录读取借用已验证的不可变清单，消除 N 次读取反复复制 N 项元数据。每块磁盘数据仍重新验证；提交替换缓存代次，旧 generation 和损坏区块仍拒绝。

过期侧车可由普通操作产生：大档自动保存已经写入原生检查点，随后持久状态变化，再手动保存或正常关闭，新的公开主档已写入，而旧原生侧车仍保留。`App.tsx` 仅在 autosave + 大档 + IndexedDB 条件下启动原生增量事务；手动保存和正常关闭均使用 `manual` 完整保存，随后只清理 IndexedDB 分块日志。下一次主档读取仍会尝试原生恢复。仅 `savedAt` 变化不会使基础校验和改变，必须有持久状态内容变化；因此本结论不泛化为“所有保存都会过期”。

相关实现为 [App.tsx](../../src/App.tsx)、[nativeSaveRecovery.ts](../../src/game/nativeSaveRecovery.ts)、[chunkedSaveJournal.ts](../../src/game/chunkedSaveJournal.ts) 与 [SaveStore](../../native/dsp-native-host/src/save_store.rs)。拒绝路径保留公开主档；本批没有修改存档格式、玩家库存或模拟生产规则。

## 离线正确性保护

RP0 的首轮持续生产对照发现，600 秒普通缓冲供料产线在 JS 快速结算中产出 9,600 个铁块，旧 Rust 候选只产出 480 个。源状态 proof 相等，仍不能证明后续生产尾段；Rust 虽报告 `supported=true`，同时明确冻结了未证明的 570 秒尾段。量子缓冲、矿脉与上传塔样本也未得到可用于等价加速比较的完整结果。探索驱动的早期归一化和 `import.meta.env` 错误单列，不计产品失败；原始报告、结果和夹具 SHA 均保留在 [RP0 基线报告](../../artifacts/rust-performance/RP0/2026-09-07T08-18-40-768Z-6be3c11f/baseline-report.md)。不同产出之间不计算速度收益。

本批前端超过 30 秒直接进入已有 JS 流程，Host 独立拒绝 31 秒及以上的自动原生候选导出。1–30 秒候选仍须证明近似秒数为零、精确校准完整、源与候选身份一致。原有 JS 快速 / 精确选择及保守结算确认保留。这是自动采用范围的正确性保护，**没有修好底层长时宏算法的产出差异**；Rust 实时玩家资格仍关闭，实时模拟继续由 JS 持有权威。

## 正式恢复矩阵

全部输入为公共引擎模板生成的暂停合成档，经过真实生产保存投影播种。每个样本先正常关闭，再以新的 App / Host 重开后计时；A/B、B/A 交错，不复用热会话。指标包含恢复入口、清单、区块 IPC、解析与校验，终点为已验证 envelope 或确认回退。

| 合成规模 / 场景 | 配对数 | 基线 → 候选中位耗时 | 耗时下降 | Native 读取条数 | 结论 |

| 19,997 实体、44,200 带 / 过期密集侧车 | 5 | 191.5 → 61.5 ms | 67.9% | 44 → 1 | 已验证阶段收益 |
| 同档 / 匹配侧车完整恢复 | 5 | 478.9 → 479.1 ms | 约 -0.04% | 44 → 44 | 基本持平，完整规范状态一致 |

共 **42/42 有效运行**，没有 RPC 失败；全部满足原始夹具字节不变、检查点身份不变、期望结果等价、正常关闭和无残留包进程。过期路径均正确返回回退结果；匹配路径完整规范状态哈希一致。三组主要对照各 5 对；两组补充样本各 3 对，不计为完整 5 对门槛。没有将补充矩阵扩展成 RP0 总体验收通过。

机器为 i7-14700KF（20 核 / 28 逻辑处理器）、约 32 GiB 内存、Windows 10 19045、平衡电源计划，见 [环境记录](../../artifacts/rust-performance/RP0/2026-09-07T08-18-40-768Z-6be3c11f/environment-candidate.json)。42 个样本均达到 `SAMPLED_COMPLETE_PROCESS_SET`，Private Bytes 采样的全进程覆盖检查通过；它是采样峰值，不能称为绝对内存峰值。只报告中位数、范围和配对方向，不宣称 P95 / P99；单机合成输入不代表所有实际工厂。
