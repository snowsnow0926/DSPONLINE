# 完整 Windows Rust 开发进度｜2026-09-09

**完整 Windows Rust Goal 已创建并启用。** 目标包含 Rust 实时运行、完整受支持玩法、可靠存档与恢复，以及可以交接发布的 Windows 包。沿用现有界面；网页/安卓 Rust 仍另行开发，本批未发布客户端。

## 本批推进

1. **大档校验更快了。** 复用数字编码缓冲与哈希视图，减少大量临时对象。11 万实体、23 万传送带的原始终局档，三对新旧测量中，两类完整校验的合计中位从 **3.871 秒降到 3.098 秒，减少约 20%**；所有摘要相同，原档未变。这是校验环节收益，完整进入游戏、帧率和内存效果仍待实包验证。
2. 本批完整游戏测试 **3,174 通过、39 条件跳过、0 失败**；实际 Rust 对照 **50 通过、1 长测条件跳过**，类型和网页构建门禁通过。首轮测试账目脚本误判了精简输出，已保留失败记录并独立核验；游戏测试本身通过。
3. 前批恢复验证覆盖 **5 个写档边界、15 次独立子进程调用**，重复命令没有再次结算。完整 Rust Host **256 通过、1 驱动入口忽略**，证据采集 **8/8**、工具和后台策略 **82/82**。仍未替代正式桌面接管或写盘中途断电验收。
4. 上一 `4bc` 提交的 Windows 云端检查全部通过，Linux 构建、单元、Server/Ops/Native 也通过；浏览器仍有 **4 项失败、1 项重试后通过**。新源码云端和新桌面包结果另行验证，整体还不能发布。
5. **新 Windows 测试包已做实际复验，终局入口仍未过关。** 文件校验通过，Rust 返回了短时结算结果，但保存后的模拟 Worker 未在原 90 秒内就绪；之后的正常关闭也未完成，脚本清理了自己的隐藏测试进程。完整成功写档和重开尚未验收。同一冻结 Rust 程序的独立固定 9 秒导出与已验证参考逐字节一致，原玩家文件未变。
