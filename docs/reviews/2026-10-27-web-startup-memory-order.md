# 大档启动检查点与快照的内存时序

状态：本地开发候选，未发布。接续 [旧缓冲引用诊断](./2026-10-27-web-obsolete-checkpoint-buffer.md)。仅清理引用已经证明可释放约 207 MB 可达二进制存储，但正常运行的进程峰值下降不稳定，因此继续处理较早的对象重叠。

默认大档 IndexedDB 路径现在先建立原有恢复基线，完成普通模拟 T0，再创建私有时间扭曲快照和它的后台副本。T0 数据仍完整接收、校验并作为原有回退状态保留；该次不再使用的 transfer 缓冲及时解除引用。保存阶段复用同一启动操作记录的 Worker、revision、注册表指纹；任一项失效或仍有普通操作未完成就拒绝旧快照，不能直接跳过检查点。

小档、缺少可用模拟 Worker 的路径以及可选 durable 协调器保留原流程。启动时钟仍在这些步骤之前锚定，不漏计或重复计时；GameState、材料、存档和备份规则没有调整。

前置 21 项启动/故障专项通过，包括运行与暂停起步、T0 回包先于快照上传、保存失败重试、真实第二标签页接管、提前退出、以及退出发生在 T0 尚未返回时禁止迟到上传。当前已完成类型与 Web 构建检查；完整回归、完整大档一致性和不强制 GC 的整页对照尚待完成，不能据此宣布峰值下降。
