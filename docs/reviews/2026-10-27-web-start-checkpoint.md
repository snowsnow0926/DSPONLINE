## 实现边界

启动仍取得原有普通模拟 T0。只对独立复制的大档私有来源使用现有 ACK 分批传输，每批重查同一启动操作、来源对象、JavaScript 权威租约、模拟屏障、空提交队列与页面生命周期。完整收齐后仍执行原投影、证明和独立读回；普通可变状态与小档保持原子快照。

启动从等待阶段起单次执行，实验性“保存时可编辑”也不能改变本次参数。写入结束释放私有来源，操作结束清理标记；页面退出永久取消本次操作，BFCache 返回不使旧回包复活，取消后普通模拟能继续。失去写入权或卸载清理来源，旧操作不能清掉新操作的进度，失败提示保持。

首个同时跳过 T0 的候选在真实大档页面无响应，未完成对照，具体根因未确认；该分支已撤销，原补丁、构建与日志保留在本机。恢复 T0 后的 DEBUG 单次诊断和初次未完成的一组均不用于性能百分比。正式数字来自当前源码的四次独立无诊断旅程。
