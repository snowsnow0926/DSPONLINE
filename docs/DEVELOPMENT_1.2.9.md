# 1.2.9：共享性能与画布交互

2026-09-10，Role: develop，开发候选，未发布。

用户范围：网页/PWA 与安卓共享性能优化；WASD 平移画布；框选生产区域并与选中节点一起移动。测试保持后台、静音、不抢焦点。完整跨端 Rust 和 Windows 实时接管不在本版本范围。

## 当前实现

- 从 Rust 开发分支 `f2f6d033` 按路径引入共享模拟、保存校验、Worker 保存与快照复用及相关回归。来源补丁保存在忽略目录 `artifacts/shared-performance-import.patch`。其中部分早期优化已随 1.2.7 上线，最终发布内容必须按正式 1.2.8 来源比较，不能全部算新增。
- WASD 通过现有 React Flow 视口入口连续平移，不提交玩法命令；输入框、输入法组合、Ctrl/Meta/Alt、弹窗、手势、隐藏页和失焦停止。
- 框选工具新增“同时选中生产区域”；完整包含的区域随选中节点实时预览和原子提交，沿用撤销/重做、保存、锁定与重叠保护。区域边界仍可独立缩放。
- 区域编辑器增加“选中区域与内部节点”，为触屏提供入口，随后切到布局模式；仅选择完整包含且未锁定的节点。
- 版本 1.2.9，Android versionCode 1002009；保留 1.2.8 正式云配置/更新保护、包名、存储 origin、签名链和香港显示补偿。
