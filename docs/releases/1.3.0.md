# 1.3.0 香港网页版发布

2026-09-22，北京时间。Role: release；用户明确授权将量子取料修复作为 1.3 版发布香港 VPS。

香港主站已于 **00:59** 切换至 **1.3.0+e8c44f8d7160**，01:02 完成公网、PWA 和上一稳定版隔离验收。入口：[香港主站](https://dsponline.cn/)、[上一稳定版 1.2.9](https://dsponline.cn/canary/previous/)。本次仅发布香港 Web；API 保持 1.2.6。上海、下载站、Android 和 Windows 未在本次发布中切换或重新验收，最近已发布版本仍见 [1.2.9 记录](./1.2.9.md)。

## 玩家可见变化

- 量子下载先核实真实可供库存，缺货高优先级请求不再占住水和其他有货物品的额度；库存不足时保留优先级，同级余数跨边界轮转。
- 建筑制造会利用仓库中的现成中间件，实际送达后恢复旧任务；缺料目标保留，同时尝试后续材料齐全的目标。
- 多中心优先补齐已收部分材料，减少唯一一套材料被分成多个半套的停工。
- 配送提示区分仓库缺货、零下载额度、等待边界、等待共享分配和实际送达；材料预览只使用对应中心可用库存，窄屏提示可见。

问题与修复证据见 [开发记录](../feedback/2026-09-21-v1.2.9-construction-quantum-fix.md)。GameState v47、envelope v2、cloud schema v8、SQLite layout v3 保持兼容；可选下载游标旧档缺省 0，配送诊断不写入保存。香港继续使用 JS 模拟，没有启用 Rust 权威核心。
