## 本次内容

- 连接点和连线圆圈提供默认、放大 25%、放大 50% 的设备级偏好，视觉尺寸、连接半径和空间索引命中半径保持一致。
- 建筑制造中心可批量设置所有已解锁建筑的制造目标，并继续受建筑仓储科技与一亿上限约束。
- 桌面和新版移动端混合选区支持原子批量增加建筑与传送带；材料不足时整批不变，建筑和线路分别遵守既有限额。
- 移动端多选在 React Flow 节点刷新后保持选择与视觉反馈，5、10、20、50 节点场景均有自动化覆盖。
- 设备偏好不进入 GameState、云存档、排行榜或状态哈希；本版没有数据格式或数据库迁移。

- 没有使用生产账号执行认证后的云存档写入 smoke，这是明确的生产数据保护边界。
- 香港根盘约 83%，上海约 80%；均低于 90% 硬保护线，但已达到或超过 80% 告警线。不得删除当前版、回滚版或有效备份。
