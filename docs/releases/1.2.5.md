## 玩家问题修复

1. 普通材料、有限缓存、真实供电和并发写入保护继续保留；已独立证明的白矩阵、科研和火箭终局域不再因为无关尾段边界到期而整体归零。
2. 建筑制造中心在同电网供给证明成立时继续消耗真实库存递归施工，纯挂机期间不再无故停工，也不会复制施工原料。
3. 大型终局档的 Worker 启动允许合法切片在 60 秒内完成；异常会释放启动锁并允许重试，Worker 内容同步异常可恢复而不再直接退出纯挂机。
4. 同标签页 Web Lock 释放竞争已修复；IndexedDB compare-and-swap 仍是权威写入围栏，外部真实写入者继续阻断。
5. 禁止自动安装历史检查点，避免内存保护把玩家进度回退；蓝图详细卡片改为自然高度和有界溢出，修复信息错位与重叠。

这次放宽只拆除了无关产线之间的一票否决和过早超时，没有取消存档结构、真实库存、真实供电、外部写入者或保存读回保护。
