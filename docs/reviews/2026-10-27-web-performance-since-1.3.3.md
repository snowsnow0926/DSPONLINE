# 从 1.3.3 到现在：性能优化报告

> 本文主体固定记录截至 `9f0d9f7072ae` 的阶段。后续持续 goal 已验证界面查询及 `b77a420df80f` 的画面恢复优化，详见 [最新一轮报告](./2026-10-27-web-idle-reveal-styles.md)：退出帧少 42.92%，进入长任务累计少 31.93%。该组以本地 `4ea4aab3` 为对照，不与本文的正式 1.3.3 对照拼接成一个总百分比；仍未发布，进入单次停顿和内存继续优化。

本报告统计正式 1.3.3 发布后的新增优化。当前是本地开发版，尚未发布；原存档、产量、耗料、配方规则和自动备份停用设置保持。

**结论：进入时的大卡顿明显减轻，停止挂机保存更快，内存压力有所下降；还没有达到全程丝滑。**

## 直接对比正式 1.3.3

使用同一台电脑、同一份约 105 MB 级大档、相同操作，新旧版本各测两次，下表为中位数。

| 玩家能感受到的项目 | 正式 1.3.3 | 当前开发版 | 结果 |
| --- | ---: | ---: | --- |
| 开始挂机时最明显的一次画面停顿 | 1.16 秒 | 0.43 秒 | 少 **62.7%** |
| 开始挂机需要等待多久 | 10.79 秒 | 10.82 秒 | 基本不变 |
| 停止挂机并保存需要等待多久 | 14.30 秒 | 12.88 秒 | 少 **10.0%**，约省 1.42 秒 |
| 游戏进程峰值内存 | 5.56 GB | 5.03 GB | 少 **9.5%**，约省 530 MB |
| 退出后恢复画面的短停顿 | 0.27 秒 | 0.33 秒 | 增加约 0.06 秒，仍需优化 |

内存有波动：新版本两次为 **4.67～5.39 GB**，旧版为 5.55～5.57 GB。这是浏览器游戏进程的峰值，不是存档文件大小，也不代表所有电脑都会得到同样比例。另一次开发过程测试出现过约 17.8 秒的开始等待，尚未查清这种偶发波动；记录已保留。

## 巨构制造计算快了多少

以下是同一大档推进固定 30 秒挂机时，以制造为主的结算计算耗时，包含递归拿料、对应校验和少量终局产率结算；不包含整个保存等待。

| 供料情况 | 旧计算 | 新计算 | 减少 |
| --- | ---: | ---: | ---: |
| 保留原库存 | 5.87 秒 | 3.93 秒 | **33.0%** |
| 从量子仓库供料的压力场景 | 1.07 秒 | 0.70 秒 | **34.1%** |
| 托盘材料充足的压力场景 | 1.72 秒 | 1.57 秒 | **8.3%** |

这是少花了计算时间，玩家获得的材料和建筑数量保持相同。量子和托盘两行使用人为供足材料的测试场景；不能理解成整款游戏帧率提高 34%。三类各做两组新旧对照，12 次完整保存正文按场景全部一致。

## 这几轮具体改了什么

1. **减轻开始挂机的大卡顿。** 恢复日志和主存档共用已准备的数据，减少主界面承担的大对象复制。
2. **及时释放用完的内存。** 解除不再使用的旧缓冲引用；保存完整结束并校验成功后，及时结束空闲保存后台，避免和新挂机计算一起占内存。
3. **减少巨构制造的重复计算。** 仍然每次查看实时库存、选择合适配方；对于完全相同的制造步骤，复用算过的批量耗料结果。高级配方优先、量子扣料和材料守恒检查继续执行。

扩大旧方案缓存、调整普通检查点顺序等没有取得足够收益的尝试，均未作为优化保留。普通检查点和存档校验没有被跳过。

- 完整单元测试 **3,688 项通过**，网页测试 **519 项通过**。
- 额外检查了多中心制造、科技改变、量子取料、高级配方、失败重试、旧存档和多标签页保护。
- 普通模拟推进 30 个模拟秒后，新旧完整状态也一致。
- 可选恢复组合 **42 项通过**，生产离线缓存检查 **1 项通过**；本轮最终门禁没有失败。
- **新增优化尚未发布**，没有操作线上玩家存档或重新开启自动备份。

仍需继续处理：开始挂机约 10.8 秒的总等待、停止保存约 12.9 秒的等待、退出画面的小卡顿，以及大档几 GB 的内存需求。手机、低内存设备、守恒模式和超长离线的完整性能资格还需单独验证。

本表采用正式 1.3.3 与当前版本的新一组直接对照，因此与各轮报告的基线不同；百分比不能相加。技术细节与全部波动记录见 [本轮验证](./2026-10-27-web-construction-ledger-cache.md)、[启动响应优化](./2026-10-27-web-startup-shared-owner.md)、[内存回收优化](./2026-10-27-web-startup-idle-retirement.md)。
