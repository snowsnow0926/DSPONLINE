# 网页性能循环：大档保存投影

Role: develop。承接 [上一轮](./2026-10-26-web-performance-loop.md)，继续优化大档打包；不发布、不改存档格式、不修改自动备份停用设置。

## 问题与改动

同一大档中，生成持久存档投影约需 1.2 秒。原 `omitSaveContractDefaults` 对每个建筑、物流槽位和传送带重复筛选同一组字段，构造默认值数组和 Map，再逐字段查询规则。规则来自已深度冻结的共享合同，记录增多时这些重复分配只增加开销。

本轮按合同声明的有限 scope/version 预先生成投影规则。静态默认值复用，记录相关的默认值仍在每次调用中计算，而且必须在删除任一字段前取完，保证 `sorterTier` 等依赖兄弟字段的默认值保持原有语义。缓存不持有记录、存档、库存或跨记录默认值，也不因任意传入版本而增长。公开 API、字段合同、格式与校验算法均不变。
