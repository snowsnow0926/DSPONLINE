# 玩法与系统基线

> **当前发布基线（2026-08-11）**：正式环境当前使用 `1.0.38 / GameState v46`。有效资产的 v43 空间站实验存档不加载；传统物流站升级与星图批量入口仍保留用于兼容现有站点，普通与速通工厂使用独立存档命名空间。

### 1.0.38 正式规则边界

- 主档、槽位、快照、云上传、普通离线和纯挂机结果可以由 Worker 生成已验证的单一可转移缓冲区；失败、取消、过期代次或完整性不匹配都丢弃候选并保留原检查点，不能通过跳产量或补物资恢复。
- 新写出的 v46 持久 JSON 只省略现有迁移会精确补回的默认零值和可重建运行时字段；非零库存/缓存/进度、在途货物、路线、蓝图、量子库存、科研、戴森、模式和排行榜事实不得省略。旧未压缩 v46 继续读取，1.0.37 客户端读取普通/速通稀疏合成档的跨版本门禁已通过。
- 普通模式中恰好只有一个健康规范单极磁石节点的暂停存档，可在持久快照、候选哈希、确认令牌和双重确认后新增第二个有限节点。新节点矿机数、缓存、库存和累计产量均为零，硬上限为两个；速通、损坏节点、ID 碰撞和重复操作拒绝。该功能不自动运行，也不批量修改真实玩家档。
- Worker 私有传送带账本、生产静态量、电网/戴森快照和量子索引只减少重复计算，不改变确定性结算顺序、资源守恒、排行榜协议或长窗口近似的既有风险边界。

### 1.0.37 正式规则边界

- 单极磁石只有一个资源实体是当前基线星系的合法生成结果，不能据此为全部存档补矿。v20+ 旧档迁移只恢复其持久星球资源目录明确声明的稳定资源节点，不再从同种子重新生成但目录不同的基线引入幽灵稀有矿。人工补回规范单极磁石必须使用只读预览、源/候选哈希、确认令牌、备份、回滚和审计信息；速通或排行榜相关存档还要求独立审核通过，工具不会被加载、导入、云恢复或排行榜提交自动调用。
- 普通离线只有精确结果或经校准和尾验的合格近似结果可以自动提交。零校准保守、超时、Worker 错误、内存风险和边界失败仅展示保守预览；玩家可从原状态精确重试或取消并保留原 `savedAt`/待结算时长。普通模式可二次确认只推进时钟且收益为零，报告明确记录原因和实际提交秒数；速通只允许精确结算。
- 桌面科技树是固定高度、禁止纵向滚动的横向视口。滚轮 `deltaY`、既有 `deltaX`、Shift 滚轮、触控板、中键/右键拖动和方向/Page/Home/End 键只改变 `scrollLeft`；聚焦科技只做横向居中。高密度层级在 100%～200% 字号下扩展为相邻横向子列，手机继续使用独立纵向列表。
- 星图顶部把“升级全部星际物流站”和“一键切换全部量子物流站”保持同排，并提供“量子网络一键接入所有轨道收集器”。全局/本系批量命令仍逐目标复用既有单站安全校验，提交前显示可成功与跳过数量，提交后保留分组跳过原因；操作不增加量子额度、不改氢气规则、不清缓存或补物资。

## 1. 产品定义

DSP极简网络是一款以生产网络为主体的 2D 平面挂机游戏。玩家不是控制机甲，而是直接用鼠标或触摸指针操作矿脉、物资、建筑和线路。目标体验是“一边读生产信息，一边在无限画布上搭建和优化工厂”。

当前原型高还原《戴森球计划》的物品、配方和科技节奏，后续需要在保持工厂网络乐趣的前提下进行原创化。黑雾与战斗不在当前范围。

## 2. 设计不变量

- 指针就是玩家代理：长按矿脉采矿，点击/拖放物资，点击端口连线，拖动节点调整布局。
- 库存对玩家只显示和结算整数；小数只允许存在于设备周期、物流进度和内部累计器。
- 发电是连续功率，不使用伪造的生产周期条；其他生产设备每完成一个周期走完一次进度。
- 时间扭曲装置只有“纯挂机”模式。开始后进入独立挂机页面，画布、建造、选择和非必要 UI 冻结；底层生产、采集、物流、电力、科研、戴森和建筑制造按权威供电倍率推进。长时宏观结算允许受保护的数值近似，但科研成本/奖励、库存非负、物流货物所有权和存档结构仍是硬门禁。停止时先完成安全分段和主存档读回校验，刷新或崩溃从持久检查点与最后完整边界恢复。
- 游戏暂停会停止全部模拟子系统和高频状态发布；暂停期间可以查看、设置、管理存档和云同步，但不会把暂停墙钟时间补算为生产。
- 传送带直接承担设备间物流和吞吐等级；分拣器 Mk.I/Mk.II/Mk.III 不再作为施工件、制造项、科技奖励或独立升级。自动模式从核心或启用内容包的动态线路目录中优先使用已解锁且有库存的最高等级，并在开始连接时锁定本次等级。
- 默认设备或未配置物流槽可以被第一条合法输入自动设定，减少“先配置、再连接”的重复操作。
- 线路必须位于建筑下层，卡片点击不得穿透到后方线路。
- 任何切换配方、回收、升级和载入操作都应保护设备输入、输出、线路库存和用户存档。
- 桌面和触摸端使用同一套游戏规则，交互可以适配但不能产生不同模拟结果。

### 1.0.35 已发布的玩家规则边界

- 离线与纯挂机分级只选择现有精确、快速或保守结算器，不改变配方、产能、物流、量子带宽、资源收益或排行榜规则；设备高风险时先提示，取消保留原存档。
- 速通百万白糖目标继续以权威累计生产 `totalProduced.universe_matrix >= 1,000,000` 判定。v46 合法速通存档若累计事实已满足但派生里程碑漏写，加载时只补齐该派生状态；普通工厂、内容包存档和未达标存档不会被补齐。服务端缺少历史完成时间时只使用当前有效游玩时间作为保守成绩，不会伪造更快时间或覆盖已有更快提交。
- 检查器新增 ±10,000 与 ±100,000 只是现有原子堆叠命令的快捷入口；仍受施工库存、唯一建筑限制和 1～100,000,000 上下限约束，不免费建造、不影响蓝图或历史安全超限堆叠。

### 1.0.36 已发布的玩家规则边界

- 设置中的“默认并联数量”表示新传送带的 `lanes`，不是货物 `stackSize`。可选 1、2、4 或自定义 1～4,096，只影响后续桌面、点击、触摸和蓝图新线路；已有线路和蓝图模板不变。新线路按最终并联数一次性扣除同级传送带，缺料时整次原子失败并显示需要、现有和缺少数量。该偏好只保存在当前设备，恢复或切换普通/速通存档不会把它写入存档或云端。
- 火力发电厂可选择目录中的 `fire_ice`，热值为 `4.8 MJ/件`，继续使用火电 80% 燃料效率、输入缓存、剩余热量、电网调度、燃料耗尽、统计、离线和时间扭曲路径。煤、原油、精炼油、高能石墨、氢及各类燃料棒的既有热值和可用建筑不变；本批没有副产物规则。
- 传送带活跃集合和物流脏缓存只减少重复查询，不改变线路容量、优先级、公平游标、目标端口、运输载具、翘曲器或量子共享池所有权。无法证明休眠、目标容量变化、源端产出、供电/配方/拓扑变化时立即回到完整精确计算；不会删除缓存、跳过生产或以补物资方式掩盖堵塞。
- 实体不少于 700 或线路不少于 1,500 的当前星球会在设备开关允许时自动使用轻量画布。普通线路仍可悬浮、点击和双击寻线，选中后提升为详细线路；Canvas 不可用时回退 React Flow。自动模式只改变渲染与命中对象数量，不改变暂停、模拟、蓝图、移动、线路或存档结果。
- 本批存档工作仅做字段审计：建筑输入/输出、生产进度、矿脉、线路进度与累计量、物流塔/量子库存、在途货物、建筑堆叠、科研、任务和戴森状态继续持久化；新增索引和空间命中均为可重建缓存。GameState 仍为 v46，不触发旧存档迁移。

### 传统物流站升级兼容面（线上 v44 / 本地 v45）

- 每个恒星系最多一座系统空间站。项目按四阶段材料清单施工，材料从同恒星系行星托盘交付；成本修正和交付库存以规范十进制字符串写入 GameState v44。有效 v43 实验资产不会自动迁入量子共享池。
- 星际物流站 Mk.I 可以原地升级为 Mk.II。每个物流站实体（无论内部堆叠多少台）消耗一份升级包：钛合金 10,000、框架材料 5,000、量子芯片 5,000、宇宙矩阵 10,000，材料只从所在行星物资托盘原子扣除；科技未解锁、材料不足、无效堆叠和已升级状态都由同一查询函数返回明确原因。升级保留实体、槽位、传统航线和在途货物，可从选中实体检查器、恒星系工作区一键升级本系、或星图一键升级全星图；批量按稳定实体 ID 顺序逐塔结算。仅本地 DEV/localhost 测试模式把这些材料成本设为 0，正式构建仍使用上述成本。Mk.II 默认仍是 legacy；切换到 elevator 会等待该站作为需求端、供应端、载具所有者或中转点的全部传统 `StationRoute` 完成，并在五秒模拟边界切换。
- elevator 站退出旧槽位伙伴匹配和逐航线派遣，使用一个通用输入缓存、最多五个独立输出物品和系统共享仓库。每种物品按稳定 key 与持久公平游标分配，输出口重复物品会被拒绝。
- 施工平台的传送带输入先进入本系工程缓存，再按阶段顺序结算；后续阶段材料可以提前到达并保留。施工平台和已运行的电梯站都受真实电网 `powerFactor` 约束，断电时输入不被吞掉。
- 同恒星系共享仓库在五秒边界上传/下载；完成联合协议后，跨恒星系请求按来源库存、目标缺口、模块吞吐、舰队空闲量和翘曲器共同限幅。货物在结算点进入目标 hub，舰队只保留聚合返回桶，不逐船写入存档。
- 跨恒星系舰队返回桶使用与传统路线相同的恒星系距离数据计算确定性冷却时间；同一恒星系不产生翘曲器消耗或跨系舰队桶。
- 旧存档不赠送空间站、Mk.II、模块或舰队；所有旧站点迁移为 `stationTier=1`、`stationOperationMode="legacy"`。未启用 elevator 的传统物流热路径不读取 hub 状态。

### 量子共享物流（线上 v46）

- 全部已接入量子塔在同一玩家存档内共同提供上传和下载两个独立额度。每个方向的基础公式均为 `5,000 件/分钟 × 银河物流无限科技倍率² × 全部量子塔堆叠总数`；固定五秒边界按确定性比例和持久公平游标分配。供需集中在少数塔上时不再受单塔堆叠限制。
- 轨道采集器可以显式接入或关闭量子采集网络。接入后只提交上传请求，不能从共享池下载，不使用物流槽、运输船或翘曲器；采集器本身不增加任何上传额度，必须与量子塔供应槽共同竞争量子塔提供的全局上传预算。旧 v44 存档中的采集器一律保持传统模式，不能静默接入。
- 量子模式只替代星际供应/需求。槽位的本地供应/需求继续使用物流运输机，保留运输机数量、起送比例、优先级和同一行星路线；量子塔与传统行星物流塔可以互相进行本地配送。`本地需求 + 星际供应` 会先由运输机收集再上传，`星际需求 + 本地供应` 会先下载再由运输机分发。
- 接入时只停止创建新的星际航线，并等待全局航线账本中与该塔或采集器关联的旧星际尾货。已有本地路线不进入桥接等待条件，接入中和接入后均继续调度、推进和返还运输机。量子模式不再创建运输船航线，也不补充或消耗翘曲器，但原有运输船和翘曲器库存保留。
- 共享库存逐物品独立设置容量，默认和硬上限均为 100 亿，允许 1 万至 100 亿的严格正整数。调低上限不删除已有超额库存，只阻止继续上传；同一边界先下载再上传，因此下载释放的容量可以立即接收新货。
- 量子上传必须扣除槽位 `minStock` 和本地运输机已预留货物；量子下载必须扣除正在飞往该塔的本地在途货物。升级前的本地输入/输出缓存、槽位配置、线路、库存和在途物资不重建、不清零，也不能被量子结算重复使用。

## 3. 开局循环

1. 在母星长按铁、铜、石、煤等矿脉获取首批资源。
2. 使用初始施工套装放置电力、采矿、熔炼、制造和科研设备。
3. 将物资拖入设备，或用传送带把输出端口连接到输入端口。
4. 建立电磁矩阵生产，研究基础科技并解锁更多设备和配方。
5. 从手动补料过渡到持续采矿、加工、供电和科研。

初始施工库存：3 台风力涡轮机、2 台采矿机、3 台电弧熔炉、3 台制造台 Mk.I、2 台矩阵研究站和 10 条传送带 Mk.I。母星物资托盘另有铁矿石、铜矿石和石矿各 100。采矿机、熔炉和制造台默认可用；施工托盘默认隐藏尚未解锁的其他建筑。

施工托盘支持标准和两行精简模式。选择设备后可点击同类已放置节点继续扩建设备组；普通点击遵循当前批量档位，按住 Ctrl 时每次固定增加 1 台并保持连续扩建。单选建筑或矿脉时，检查器也提供消耗 1 台施工库存的“快速增加”按钮。

科技首次完成时，其直接解锁的每种普通建筑各加入施工托盘 2 个；建筑制造中心等巨构不参与赠送，必须完整消耗施工成本。加载已经完成该科技的旧存档不会重复补发。施工托盘小锤子在直接材料不足时，可递归调用已解锁手工配方合成上游材料；只有完整链可满足最终建筑时才一次性扣料，成功后短暂显示实际消耗。无法完成整链时，灰色锤子单击定位当前真正可制作的上游物品；科技、原矿或设备专属配方阻塞分别给出原因，不使用双击。

## 5. 生产与手工制造

- 矿脉实体可由玩家长按开采，也可部署对应采集设备。
- 生产设备从输入缓存按配方周期消费并向输出缓存结算整批产物。
- 熔炉、制造台、化工厂、对撞机和研究站可在选中卡片后直接切换合法配方。
- 输入原料与输出产物都能点击取回或拖到其他节点/物资托盘。
- 基础物料和原版允许手搓的中间件尽量进入手工制造目录。
- 手工队列最多 20 项，按真实周期推进；缺料或所在行星不匹配时保留队列并显示等待原因。
- 建筑制造与手工制造使用紧凑多行多列目录，模式与搜索工具在滚动时固定置顶，并按模式分别保留最近 3 条搜索。
- 建筑制造和物品手工中的可手搓缺失材料都可直接跳转到对应手工配方，并自动搜索、定位和聚焦目标物品；没有手工配方的资源仍保持普通缺料提示。
- “空间翘曲”科技同时开放两条配方：原有 `1` 个引力透镜制造 `1` 个空间翘曲器，以及 `1` 个引力矩阵制造 `8` 个空间翘曲器。递归制造优先尝试引力矩阵精简路线，完整材料链不可完成时回退基础路线。
- 紫糖科技解锁建筑制造中心：它从所在行星物资托盘取料，按目标库存补足建筑、物流运输机和物流运输船，并递归制造缺少的可加工中间材料；载具成品进入全局随身载具栏，原矿等基础资源仍必须由玩家提供。同一物品存在多个配方时，自动规划优先尝试已解锁的高级、稀有资源或精简配方；整链因科技或材料不可完成时回退基础配方。每步生成的必要中间产物按后续步骤真实净需求完整保留为 WIP，不受固定 100 万阈值、普通建筑缓存安全上限或行星托盘上限阻断；额外副产物先进入当前行星托盘，托盘已满时只销毁任务后续不再需要的新增副产物，目标建筑、必要中间料和玩家原库存绝不删除。暂停、断电和缺料只会等待，条件恢复后从原阶段继续，不重置进度或要求手动重启。高堆叠或复杂多目标进入确定性“计算保护”时，相同目标按批结算且未完成 job/WIP 留到下一模拟步骤，其他生产、传送带、物流、电力和统计仍继续；保护只影响本次制造吞吐，不修改目标、不清空缓存，也不写入存档字段。界面显示每项 WIP、累计销毁副产物、实际配方、回退原因、当前阶段、进度、预计时间及真实的暂停、供电、缺料或高堆叠保护原因。基础速度为中间材料 0.1 秒/件、建筑成品 5 秒/个，绿糖和白糖升级同时提高库存上限与两阶段速度。画布节点使用真实约 2× 宽高和独立巨构状态区，不能用视觉 `scale()` 伪装尺寸。

修改配方时同时检查：设备兼容、科技前置、手搓可见性、来源反查、生产规划、内容审计和旧存档迁移。

## 6. 物流

### 行星工业档案

- 新工厂一次性生成并持久化星区种子；该种子确定 8 个恒星系、22 颗行星的恒星参数、二维坐标和生态档案，同一存档在重载、离线模拟和跨设备同步后必须完全一致。
- 16 种生态模板控制普通矿、稀有矿、海洋类型、潮汐锁定、矿储、采矿、风光地热、轨道采集、航程、工业专长、勘探时间和殖民成本；保存加载不得重新抽取已存在档案。
- 水只在水海洋无限抽取，硫酸只在硫酸海洋无限抽取；熔岩与冻结海洋不冒充普通水源。气态巨星的氢、氘和可燃冰产率由本星球实际档案决定。
- 同恒星系运输按轨道跨度计时；跨恒星运输按持久化二维星区距离、两端航程环境、多跳路径和翘曲条件计算。诊断、预计吞吐与实际运输共用同一经济函数。
- 星图直接显示实际资源、海洋、稀有矿、能源倍率、殖民成本和推荐工业角色；玩家设置的工业角色只用于管理标注，不暗中改写产量。

### 行星内线路

- 端口单击即进入连接状态，虚影随指针移动。
- 待定、可连接和不可连接分别使用青、绿、红反馈，并给出成功或失败原因。
- 支持多条同物品或多物品连接，不得把“第一条端口成功”写成单端口全局锁。
- Mk.I/Mk.II/Mk.III 及内容包 4～32 级线路按动态目录提供不同吞吐，支持优先级、1/2/4 层货物堆叠、监控和批量升级。已建线路可用 `-1`、直接输入或 `+1` 调整并联数量；增加消耗同级传送带，减少返还施工托盘，吞吐随数量变化且不改写等级、形状、优先级、端口和在途物资。普通线路并联范围为 1～4096；蓝图、“同步首条设置”和“应用整网”使用同一数量与物资守恒规则。逐条点选时第一条被玩家点选的网络保持为显式同步模板，不按 ID、创建时间、数组或画布位置重排；框选或全选没有顺序时必须由玩家指定并高亮模板。同步前展示并联、堆叠、优先级、线路形态、监测和路由摘要，完成后报告成功、跳过和失败数量；累计运输、实时流量、进度和在途物资不参与同步。完整拆除继续使用回收命令。无需预先点击传送带按钮；高级库存耗尽时自动降级，已有并行线路优先沿用原等级，玩家仍可手动锁定任一级别。
- 普通建筑、矿源和四向分流器都严格按高（2）→标准（1）→低（0）分配；同级线路使用持久游标轮流均分，只有较高等级全部堵塞或达到吞吐上限后才回退。单步转运不得因来源输出缓存小于多条线路总吞吐而让后续线路长期饥饿。
- 线路支持曲线、自动避让、上绕、下绕与手动高度。
- 连线前显示预计吞吐、供给、需求和潜在瓶颈。

### 物流站

- 行星与星际物流站均提供 5 个独立物品槽。
- 每槽分别设置本地/远程供应、需求或仓储、库存上下限、最低装载率和优先级。星际需求槽还可选择直达、优先中转或强制中转，并设置每船 1-4 个翘曲器预算。
- 未配置槽可以由合法连接物品自动占用：已有同物品槽优先复用，否则按顺序使用第一个空槽；不得覆盖玩家手动配置，五槽已满或方向/物品冲突必须给出具体原因。
- 黄糖科技解锁物资配送枢纽，三个输入接口可分别保持自动识别、手动指定物资或禁用。首次合法物资只绑定实际进入的接口；修改一个接口不得重配其他接口。重置已连接接口必须确认，随后只断开该接口的线路，返还并联施工件，并把线路缓存与在途物资完整退回所在行星托盘。进入枢纽的物资直接加入建筑所在行星的物资托盘；枢纽只以托盘真实剩余容量限制正常接收，不受普通建筑缓存上限截断，保护性返还允许暂时超限。低线路优先级只控制竞争顺序，不限制可累计数量。
- 每颗行星独立设置单种物资托盘上限，范围为 1,000 至 100,000,000，并提供 1 亿预设。降低上限保留已有超额库存；达到上限后自动入库停止新增，设备缓存、配送枢纽输入和待领取奖励必须留在原处。玩家主动放下手持载荷时必须整组存入并允许暂时超限，防止光标被永久占用。
- 殖民前哨的普通材料从玩家当前所在行星物资托盘统计和扣除，物流运输机、物流运输船从全局随身载具栏统计和扣除；装站或在途载具不计入。必须先验证全部条件再统一扣料，不能部分扣除。星图固定显示每项成本来源、当前/需求数量，并分别报告科技、前置星系、勘探、材料和载具缺口。
- 星际物流站可启用为中转枢纽并设置高/标准/低优先级。多跳路径要求所有 waypoint 枢纽存在且供电；停用策略、缺枢纽、缺翘曲器和枢纽断电都必须给出不同反馈。
- 星际物流站可选择自动补充空间翘曲器并设置目标库存，来源固定按塔内输入、未被航线预留的塔内输出、本行星物资托盘依次使用；不能跨行星取料，也不能挪用已预留数量。多个站点按实体顺序竞争托盘库存，并分别显示补充来源、预留量和缺口。新建到物资配送枢纽的输入传送带默认低优先级，玩家显式修改后的优先级必须保留。
- 行星与星际运输都支持供应端主动送货和需求端主动取货。供应端拥有载具时使用供应槽最低装载率，需求端拥有载具时使用需求槽最低装载率；同一物品可同时由两端派车，但载具和货物不得重复预留。航线记录载具所属站，完成后载具归还所属站。星际航线还维护总距离、最长航段、waypoint 路径和实际翘曲器消耗；同一恒星系内不预留也不消耗翘曲器，只有跨恒星系航段按策略扣除；取消航线或回收站点不得吞掉已扣翘器。
- 轨道采集器是自供能的气态巨星基础设施，不能被普通行星电网缺失误判为航线断电。高运输量下若所有运输机或运输船都在执行任务，状态显示安装/忙碌数量和“舰队容量瓶颈”；内部储能、电网不足、缺载具和全部载具忙碌保持不同诊断。
- 物流 peer 匹配在一次模拟会话中使用按物品、模式、行星/星系建立的非持久索引，并缓存同一供需站与路线策略的经济计算。需求槽会继续尝试全部合法供应源，单塔不足时允许多个供应塔在同一步部分补足；同级候选按持久化公平游标轮换，阻塞原因分别报告库存、载具、电力、翘曲器和容量。索引只优化候选查找，不改变稳定排序、route owner、装载量、翘曲器扣除或最终状态哈希，也不进入存档。
- 闲置物流运输机和运输船统一进入底部随身载具栏，可随玩家跨星球，并在当前星球的行星/星际物流站检查器中按目标数量直接装卸或一键填满；执行任务中的载具不能卸载。蓝图可保存每座物流塔的载具目标，部署后从随身栏原子装载，库存不足时只装入现有数量并报告缺口；已经装站或正在航行的载具仍归所属站点和航线管理。
- 光标可托住一组物资跨星球切换，模拟一次“手托物资”运输；其他托盘库存不会瞬移。

### 诊断

连续网络按线路和实体组成网络快照，显示流量、容量、利用率、拥堵、断料、上游和下游。星图进一步汇总跨星球/跨恒星航线，显示完整恒星系路径、航程、周期、吞吐、能耗、翘曲预算，并诊断缺槽、缺载具、缺枢纽、缺翘曲器、枢纽断电和拥堵。

### 资源与设备回收

- 新增建筑与采集设备的单节点堆叠上限统一为 1 亿，手动扩建、批量放置和蓝图部署共用同一安全整数校验。历史存档中已存在且仍处于 JavaScript 安全整数范围内的超限堆叠会原样保留并显示警告，只允许减少或回收，不能继续增加；超过 `Number.MAX_SAFE_INTEGER` 的危险数量拒绝载入，并要求玩家保留原文件进行受控救援。建筑、线路和施工库存的返还相加必须保持安全整数，越界时整次回收不执行。
- 澜渊 II、赤砂 I、牧云 II 固定包含原油，储量依次体现海洋基准、高储量荒漠和中等储量草原；风暴 I 只在命中含油生态模板时生成油田。
- 有限模式下，节点、检查器和统计必须显示剩余储量、初始总量与比例，归零后统一显示“资源已枯竭”。枯竭节点在矿机覆盖下仍保留可点击的高亮，并提供经确认切换到资源设置的入口；减少动效或性能模式使用静态高亮。只有无限模式或行星档案中真实匹配的水/硫酸海洋可显示“无限”；有限原油涌泉不能标成无限。显式为零的有限储量保存重载后必须继续为零。
- 无限科技“矿脉极限利用”每级同时提供固体采矿速度 `+10%` 和固体矿脉消耗 `-10%`，Lv.10 起固体矿脉不再减少储量。低于 Lv.10 的小数消耗以存档内 0～9 整数余数累计，不用浮点库存。按 1.0.6 的紫色矩阵配方，默认有限星区生产 Lv.1～Lv.10 所需 49,620 个宇宙矩阵后，限制资源煤矿仍剩 2,182,901，约为实际消耗 428,868 的 509.0%，满足至少 300% 余量。
- 采矿机、原油萃取站和抽水站属于资源节点上的安装数量，不替代矿脉/涌泉/海洋节点。检查器可回收指定数量或全部采集设备，返还施工托盘；剩余资源、周期进度、输出缓存、线路和线路货物不得删除。
- 普通堆叠建筑可逐台 `+1`，减少时支持目标数量、`-1`、`-10`、`-100` 和“减至 1”。最低保留 1 台，完整拆除继续使用独立确认；减少的建筑完整返还施工托盘，输入、输出、燃料、进度、物流槽、闲置/执行中载具、线路与在途货物均原位保留。v32 将建筑物品缓存分为“生产建筑”和“仓储与物流建筑”两项存档级安全上限，默认均为 1,000,000，可在 1,000～100,000,000 内独立设置。生产、资源采集、燃料、仓储、分流和物流槽按建筑 `kind` 选择对应上限，每一种输入、输出和每个物流槽分别计算；物流槽非零手动上限还会与额定容量、全局仓储物流上限取最小值。物资托盘、施工库存、载具、翘曲器、传送带堆叠、MJ 储能和建筑制造中心目标库存不受影响。
- 调低缓存上限或执行 `-1` 时必须保留输入、输出、生产进度、线路物资、在途物流和超额库存；库存回落前暂停新增输入、生产和派遣，已在途货物仍可到达。调高后立即恢复可用容量。运输机、运输船和翘曲器泊位继续按物流站堆叠数量增长；数量降至 1 后再次减少才进入完整拆除流程。
- v33 增加每台设备的增产剂缓存上限，默认 600、合法范围 1～100,000。增产剂耗尽后设备按基础倍率继续运行并显示“增产剂耗尽”，补充后自动恢复；已有喷涂点和调低设置后的超额库存不得删除。
- 已安装喷涂模块可从桌面或手机检查器拆卸。拆卸会返还模块、缓存增产剂和剩余喷涂点折算物；保护性返还允许托盘临时超额，相关专用输入线按既有回收规则退回，建筑随后按无喷涂的基础倍率运行。
- v35 起普通建筑可单栋或批量锁定。锁定只阻止移动、回收、堆叠、升级、配方与物流等配置修改，不暂停生产、供电或运输；从锁定卡片主体拖动应平移画布。蓝图可以读取锁定源，但粘贴的新建筑默认解锁。
- v28→v29 迁移按 `vein_<planetId>_crude_oil` 稳定 ID 补充缺失油井；若该行星已有任意原油节点，则保留旧节点并跳过补充，重复迁移必须幂等。

## 7. 电力

- 风力、太阳能、地热、火电、聚变、人造恒星、射线接收和储能共同组成能源层。
- 太阳能功率由行星光照、宿主恒星亮度和潮汐锁定加成共同决定；风力和地热分别使用本行星环境倍率。
- 风电、太阳能、地热等无需燃料的电源优先；火电只按实际电网缺口燃料。
- 火电可使用煤、原油、高能石墨、精炼油和氢；聚变与人造恒星使用对应燃料棒。人造恒星的反物质燃料棒额定缓存为每台 30 个，减堆或旧存档超额时保留完整库存并停止继续补入。
- 同一行星同一电网内的发电设施全域供电，不再计算覆盖半径；设备仍按电网、发电优先级和消费优先级分配功率。
- 状态必须区分缺燃料、未选燃料、无电、低供电、待机和正常运行。设备供电分配与工作利用率是两个独立指标：满额供电但缺料或堵塞的设备仍显示 100% 供电，生产利用率可以为 0。
- 蓄电器和能量枢纽支持充放电与跨星球能源物流。

## 8. 科研与阶段推进

科技按前置关系排队，完成后自动开始下一项；移除前置科技时要级联处理后续无效队列。当前普通科技可以暂停或取消，已投入矩阵按科技保留；暂停项可一键继续，取消项重新选择后从原进度恢复，依赖它的队列项目在前置完成前不会开始。未设置研究项目的科研站可以预接六色矩阵输入；完成或切换科技后仍需保留已连接端口和线路，移动节点不能让合法线路消失。新工厂仅开放母星，完成“星际物流系统”后开放烬原与气态巨星。新版手机科技列表必须把五条无限科技与普通科技放在同一可筛选目录；完成宇宙矩阵后默认“可研究”筛选可见全部未封顶项目，未完成时显示真实前置条件，空结果提供清除筛选入口。

五条终局科研使用确定性整数成本表。矩阵压缩、矿脉极限利用、银河物流协议和恒星能量驯化最高有效 Lv.1000，Lv.11 起分别按 1051/1000、1048/1000、1052/1000、1050/1000 复利；连续体演算按 1045/1000 增长并在 Lv.23 达到 30 天离线上限。当前投入以规范十进制字符串持久化并用 BigInt 结算，超过旧上限的等级保存为历史等级，迁移结转不得丢失矩阵投入。

主要 progression：

1. 基础采矿、熔炼、制造和蓝色矩阵。
2. 原油精炼、塑料化工和红色矩阵。
3. 跨星球钛链、行星物流和黄色矩阵。
4. 粒子宽带、处理器和紫色矩阵；信息矩阵每周期统一消耗 1 个粒子宽带与 2 个处理器。
5. 对撞、量子材料和绿色矩阵。
6. 戴森云、临界光子、反物质和白色矩阵。
7. 戴森球永久结构、跨恒星工业、无限科研和银河出口。

战役中心将该流程组织为八章主线，并提供存储、电网、线路升级、稀有资源、增产剂和蓝图等支线任务。

## 9. 戴森与终局

- 电磁轨道弹射器发射太阳帆，帆具有轨道寿命并形成发电能力。每台弹射器保存当前恒星系内的目标太阳帆轨道，桌面、新版手机和批量检查器都可修改，蓝图也保存显式目标。轨道被删除、失效或不属于建筑所在恒星系时，设备保留太阳帆输入和发射进度并暂停，直到玩家重新选择合法轨道。
- 在轨太阳帆和已吸附壳面太阳帆的基础功率均为 88 kW/帆；永久结构点保持 960 kW/点。模拟和存档始终使用 kW，界面统一按 `kW → MW → GW → TW → PW` 自动换算，并可查看精确 kW；不得为显示而改写底层数值。
- 每个恒星系独立保存戴森云轨道、在轨太阳帆、壳层计划、永久结构、壳面帆和发电收益；一个恒星系的戴森功率不能被另一个恒星系直接接收。
- 戴森球壳的吸附容量按边界结构点独立计算，1.0.5 将每结构点容量从 20 提高到 40，标准单壳上限由 5,000 提高到 10,000；多层壳分别计算，吸附速度和单帆功率不变。
- 太阳帆、永久结构和壳面帆收益按宿主恒星亮度缩放；射线接收站只使用所在恒星系的戴森功率发电或生成临界光子。
- 垂直发射井消耗小型运载火箭建设节点和框架。
- 每个恒星系最多规划 8 个壳层，配置半径、倾角和升交点。
- 当前壳层可以复制为临时 UI 模板并在另一已解锁恒星系新增一层；半径、倾角、节点、框架与壳面拓扑保留，ID、施工进度、结构点和吸附帆不复制。副本用粘贴瞬间的系统累计结构点和壳面帆作为分配起点，不会继承历史余量，但后续新发射的火箭和新吸附的帆可以正常建设副本。
- 只有边界框架完工的壳面才能吸附太阳帆并转化为永久结构。
- 白色矩阵之后开放五条可重复科研和四类银河出口，产生银河积分和终局评分。
- `galactic_material_exporter` 是可制造、可部署的四输入银河物资出口巨构，分别接收宇宙矩阵、太阳帆、小型运载火箭和反物质燃料棒。四种物资共用唯一领域目录，连接校验、节点端口、真实传输和活动结算不得维护分叉列表。未取得有效活动配置或活动尚未开始时不消费缓存；开放后长期有效，活动墙钟不受暂停、普通倍率、时间扭曲或画面刷新频率影响。
- 点击已放置的银河出口会进入“生产统计 → 银河”任务页；任务页可以查看四项进度、暂停/恢复出口或定位回设备。
- “宇宙联合空间站巨构建设任务”长期开放，四项个人目标各 100 万；四项各 10 亿的全服假数据曲线仍只在最初 72 小时模拟并在终值冻结，不决定参与资格。任何玩家无需登录即可继续交付，贡献只保存在本地存档；服务器贡献确认、真实全服累计、跨存档去重、奖励发放和空间站本体属于后续范围。
- 微型黑洞连接装置提供三个独立通用输入端口，可销毁所有允许上传送带的物品。放置后默认暂停，首次启动要求两次确认；物品只有在合法线路完成转移后才销毁，每个端口的物品类型和累计销毁量使用规范十进制字符串精确保存。时间扭曲装置和微型黑洞都是唯一巨构：新的单体调整、蓝图和混合批量增加都不能提高节点堆叠，批量预览与执行会明确跳过且不扣库存。正式旧版本曾生成的正安全整数历史堆叠必须原样保存、导出和云同步，运行能力仍只按一个节点生效；不得在加载或上传时静默截断额外数量。
- 时间扭曲装置是全存档唯一生效的模拟主控，不能堆叠倍率。玩家请求 5x 及以上整数倍率；4x 待机功率为 100 MW，此后每增加 1x 功率需求乘 10。电网只用分配完普通负载后的剩余功率供给主控，供电不足时自动降到可稳定维持的最高档并保留请求值，供电恢复后自动回升。`pure-idle-macro-v3` 启动和恢复时重新计算供电允许倍率；请求倍率只改变宏观结算的模拟时长，不让算法工作量随倍率线性增长。有限科技和无限科技使用实测投入率、整数余数和 BigInt 成本推进，奖励、队列与等级边界继续调用原有领域规则。普通合同、尾验或 Worker 不满足条件时转为保守宏观并可冻结不确定产线，允许少发收益但不得整段精确重放、负库存或复制货物。点击停止会冻结目标墙钟时间并复用当前已校准 Worker，忽略退休 Worker 的迟到消息；候选只有通过正式序列化、重载、数值门禁和主存档读回后才提交。写盘失败保留同一冻结边界、检查点和可用 Worker，界面提供原因、重试与明确放弃未结算时间；只有成功保存后才清理 IndexedDB 恢复记录。页面后台最多保留 5 分钟高倍率，超过尾段按普通快速离线结算；离线结算与活动时钟始终使用真实墙钟，不享受扭曲倍率。

- 设备级离线策略提供“自动：失败后询问”（默认）、“始终精确”和“失败后优先跳过”。`fast-30s-v2` 对不超过 30 秒的离线时间使用精确路径；长时间离线先执行最多 30 个模拟秒的 Worker 校准，普通资源、缓存和运输量保留诊断误差，白糖累计生产、戴森结构/火箭/太阳帆和发电功率进入关键尾验。合同失败、校准超时、Worker 重启、低内存或零校准保守结果不得自动提交；即使设备偏好“优先跳过”，每次也必须二次确认零收益。取消、刷新、无效源或保存失败均保留原主档，成功候选必须通过 envelope v2 序列化、`inspectSave()` 和 GameState v46 重载。

## 10. 运营与辅助系统

- 生产资料库：统一提供物品与配方、建筑设施、物流运输、电力与能源、星球与资源、戴森工程、科研与机制。建筑图鉴从实际内容目录显示类型、等级、用途、解锁科技、制造材料、耗电/发电、缓存、速度和适用配方；生产配方显示单次耗时、单次产量与设备实际每分钟产量，传送带通过动态线路目录显示核心与内容包等级的基础和堆叠吞吐。
- 物品悬浮卡通过应用级行为注入提供“定位”和“打开图鉴”；鼠标可从触发物移动到 Portal 卡片继续操作，触摸端支持点击或长按且操作目标不小于 44px。无已部署生产来源时定位按钮禁用并说明原因，图鉴入口仍可查看目录资料。
- 物品详情可定位当前行星所有生产该物品的设备，并沿真实入线递归高亮上游建筑和传送带。一个目标直接居中，多个生产节点支持逐个切换或全部适配视口；当前行星没有目标时列出其他行星并允许显式跳转。高亮是瞬时 UI 状态，可独立清除且不改变选择或生产。
- 聚焦配方：主界面可拖动的横向小面板，完整展开或只看前后两层。
- 统计中心：物品流量、电力、效率曲线、设备故障、连续网络和生产规划；生产统计默认汇总全星区，也可按星球筛选，星球名称同时显示所属星系，切换筛选不重置时间范围、排序或搜索。
- 生产管理：统一查看所有已殖民行星的设备、产能、效率与状态；缺料链显示缺失输入、入线、上游设备和原料源，堵塞链显示出线和下游，并支持直接定位。筛选结果可跨行星批量改兼容配方或套用一个物流槽模板，其他槽位和各行星库存必须保持独立。
- 蓝图：框选、复制、旋转、镜像、配方覆盖、外部端口和缺料施工队列。已安装采集设备的资源节点可以作为不可建造锚点收录；粘贴只匹配附近同类型现有矿脉并补齐到目标矿机数，不复制矿脉、储量或无限状态，重复粘贴也不会继续增加已满足的采集设备。画布选中状态由权威 UI 选择集合保持，不因模拟刷新或节点重派生丢失；选中节点使用持续边框、底色和标记。
- 蓝图导入在桌面、新版手机和经典手机的横竖屏界面均提供有文字的文件入口，同时保留粘贴 JSON；交换格式版本、结构字段和内容完整性错误分别显示具体原因，成功导入后显示建筑与线路摘要且不会覆盖已有同 ID 蓝图。新建或增加并联传送带后，检查器选中实际受影响的线路 ID；线路匹配同时使用起点、终点、物品、目标端口和等级。
- 从输入或输出端口开始拉线时，起点建筑和至少有一个兼容端口的当前行星建筑会显示静态卡片高亮；鼠标拖拽、单击连线和触摸连线共用同一草稿。高亮只提示可尝试端口，不放宽同星球、线路等级、施工库存、重复线路、锁定或端口容量校验；成功、取消、Escape、切换星球或离开画布后立即清除，且不写入存档。
- 运营中心的“物流管理”按星系、星球和物流节点树形浏览，并通过跨星球领域命令编辑物流塔与轨道采集器，不切换当前行星。搜索、筛选和展开偏好只保存在设备本地；修改槽位物品前必须确认其库存返还、线路拆除和任务取消影响。施工托盘的回收模式复用单选、多选和框选，确认时展示建筑、相关线路及预计返还，并只调用既有领域回收命令。
- 画布整理：按物流上下游自动排列当前行星或选区，并可单独撤销最近一次整理，只恢复节点坐标。
- 生产区域：在空白画布拖拽创建持久化矩形标记，可编辑名称、背景色和边框色；选中后四边和四角可调整尺寸，区域位于建筑与线路下层，不拦截正常生产操作。
- 运营中心：警报、成就、难度、性能、存档、内容包、反馈和诊断；存档页显示 IndexedDB 后端、各副本大小、浏览器占用和可用配额。删除手动槽位、单份快照或明确勾选的多份快照前必须连续确认两次并显示目标。
- 当前行星物资托盘管理支持搜索、全选、删除一半和全部删除；全选作用于完整库存而非当前搜索结果，最终删除必须二次确认并按执行时真实库存限幅。
- 物品、库存、制造、戴森、银河、活动、排行榜和存档摘要中的大数量共用“万/亿/科学计数”格式；桌面悬停或聚焦、手机点击数字可查看完整精确值，百分比、日期、倒计时和普通小数速率不经过该格式器。
- 本地存档：生产统计曲线只保留在运行内存，刷新后重新积累；主档、备份、快照和三个槽位使用 IndexedDB，必须完成写入和读回校验才显示成功。旧 localStorage 存档验证迁入后才删除；页面突然关闭只保留一份可在下次启动迁回的主档急救镜像。自动快照最多 2 份、间隔至少 5 分钟，手动槽位和手动快照绝不被自动清理；空间不足时必须提供立即导出当前进度。自动保存可选 30 秒、60 秒、120 秒、10 分钟或关闭；关闭只停用周期性本地保存，手动保存、导出和云同步仍独立可用，并明确提示未保存进度风险。进入游戏前的离线结算可由玩家放弃，放弃只进入保存时的原状态、不发放离线收益，并把新的当前时间写回存档，避免重复提示同一离线区间。
- 本地存档后台化：主档、已验证手动槽位和快照把稀疏持久投影、校验和与 JSON 序列化放进 `save.worker.ts`，通过带 payload 哈希/长度的可转移缓冲区返回；一次只允许一个主档写入，后续请求合并为最新状态。同一不可变状态在已验证主键仍存在时跳过重复序列化和写入，Worker 不可用或生成结果读回校验失败时使用旧同步路径，不会用旧 revision 覆盖新状态，不改变存档 envelope v2 或 GameState v46。
- 1.0.38 稀疏存档只省略 v46 迁移会精确补回的实体/传送带默认零值和可重建运行时字段；所有非零库存、输入/输出缓存、进度、拥堵、流量、在途物资、蓝图和量子库存必须保留。旧版未压缩 v46 envelope 继续直接读取，导入/恢复失败不写回现有主档。
- 运营数据：网站访问、进入工厂、关键工作区与里程碑只按匿名白名单事件聚合；详细数据仅在受保护 `/admin` 后台展示。
- 云账号：未绑定邮箱的旧账号可在登录后绑定并验证；验证后可邮件重置密码，主存档每 10 分钟自动同步。邮件发送器未启用时相关入口标注“正在开发中”，但现有账号登录和已验证账号的云存档继续可用。云端主存档和手动槽位 1/2/3 相互独立，冲突必须由玩家选择版本，自动上传失败不影响本地存档。大存档上传先在 Worker 完成离线准备；玩家可选择跳过离线并上传当前状态，不能因此产生离线收益。浏览器压缩请求持续消费 gzip 流，5 秒压缩安全超时后在原始请求不超过 30 MiB 时回退明文；网络超时先核对云端 revision、`stateChecksum`、`savedAt` 和摘要，已提交则只认定同一 payload，未提交最多用同一 `expectedRevision` 重试一次，无法确认时明确提示状态未知。所有准备、压缩、发送和等待阶段使用进行中提示，只有服务器确认新 revision 后显示成功。云存档服务同时兼容旧蓝图普通建筑残留的 `quantumTarget: false`；客户端读取后只在星际物流站实体和蓝图模板保留该字段，普通建筑会在下一次保存前清理。格式无效、内部校验失败和请求体积过大必须分别提示，不能把体积问题误报为格式问题。
- 1.0.35 补充：纯挂机提交使用 `[lastSettledAt, currentTargetTime]` 的前向游标，同一停止、暂停恢复、页面重进、刷新、云恢复或快速点击事件不会重复处理同一段。`currentRunStartedAt/currentRunElapsed/currentRunProduction` 只表示当前运行；`totalIdleTime/totalProduction` 只表示已验证提交的历史累计。宏观候选还必须满足有限矿脉有效消耗与 `totalProduced` 的守恒约束；输出端、传送带、物流/量子容量不足时不允许先扣矿脉再丢产物。
- 1.0.38 单极磁石扩容是玩家主动的普通模式存档操作，不是迁移或自动补偿：只接受暂停、明确 `normal`、恰好一个健康规范节点且星区目录一致的存档；先持久保存“增加第二个单极磁石矿脉前”快照，再使用候选哈希/确认令牌和双重确认新增固定 ID 的有限节点。新节点矿机数、缓存和累计产量均为零，硬上限为两个；速通、重复执行、ID 碰撞、损坏节点和超过上限全部拒绝。历史超过两个的旧存档仍可读取并警告，不能自动删除玩家资产。
- 速通与普通模式：`GameState.mode` 和 envelope 顶层 `mode` 必须一致，模式参与本地自动保存、快照、手动槽位、导入导出、云端槽位/历史、冲突、删除与排行榜校验。普通模式缺失标记的旧存档安全迁移为 `normal`；只有明确的 `speedrun` 标记才允许速通提交。速通存档可显式复制为普通副本，副本不计入速通榜且不能反向升级；同一用户同一槽位的云端普通/速通记录独立保存。
- Android 原生应用的云上传不使用 gzip Blob，直接发送有 30 MiB 安全上限的原始 JSON；这只绕开 Capacitor 原生桥的二进制正文限制，不全局关闭原生 HTTP。Web/PWA 继续使用流式 gzip，只有首次压缩请求真正收到 `REQUEST_ENCODING_INVALID` 时才以同一 `expectedRevision` 明文重试一次；用户取消绝不回退，409、网络超时与状态未知继续执行远端修订核验。本地存档在全部失败路径中保持不变。
- 普通排行榜的“实际结算吞吐”只使用本地 60 秒累计生产窗口或服务端相邻主云修订的 `totalProduced` 增量；没有两个至少相隔 60 个模拟秒的主云修订时显示尚未形成窗口，而不是用机器标称速率补齐。名义速率同时显示“当前星球理论速率”“全星区理论速率”和“全星区理论峰值”：完整存档的全星区值以全部 `planetMetrics` 同名指标的饱和和计算，根 `metrics.totalItemsPerMinute` 只代表当前星球 UI 快照；历史存档没有完整行星指标时明确标记 `legacy-active-planet-v1` 回退，绝不伪造全局值。名义速率不进入实际吞吐排序，也不抬高新口径银河综合分。
- 渐进教学：先用 5 步真实命令导览收纳、制造、放置/堆叠、连线和选择科研，再用 13 步覆盖采矿、基础自动化、蓝糖、石油红糖、黄糖、星际物流、戴森云、临界光子和白糖；已配置目标会优先定位停机设备或零流量输入线，否则打开对应配方、科技、星图或戴森规划。

## 12. 内容修改的完成标准

新增或修改物品、配方、建筑、科技时，至少完成以下闭环：

1. 更新类型 ID 与核心目录。
2. 更新来源、用途、配方速率和设备兼容性。
3. 更新科技前置、施工成本和托盘可见性。
4. 验证手搓、自动生产、物流端口和整数结算。
5. 更新存档迁移，保证旧存档不丢库存或引用。
6. 运行内容审计、progression audit、相关引擎测试和关键 E2E。
7. 更新本文件中受影响的稳定规则，而不是记录临时实现细节。
