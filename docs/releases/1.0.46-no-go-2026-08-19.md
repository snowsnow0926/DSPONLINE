# DSP极简网络 1.0.46 生产发布 No-Go 记录

> 日期：2026-08-19
> 候选：`1.0.46-d64b9ef85f9d`
> Build ID：`1.0.46+d64b9ef85f9d`
> 固定源码：`d64b9ef85f9dea1cf2d0617cb300fa492ca1f43c`
> 结论：**公网 PWA 门禁失败，已完整回滚；该候选不得再次发布。**

## 结论

冻结 Web/API、Windows、Android 与下载页制品的清单、大小、SHA-256 和签名门禁均通过；Android APK/AAB 使用批准的长期证书，Windows setup 继续明确为 `NotSigned`。香港与上海完成 schema v7/layout v2 到 schema v8/layout v3 的受保护桥接、备份、不可变目录安装和 1.0.46 原子切换，上海下载页与 native stable 也曾切换到 1.0.46。

最终公网 Chrome 门禁发现 1.0.46 Service Worker 无法在全新浏览器中完成安装，因此本次发布判定 No-Go。没有使用 Nginx 别名、服务器热编辑或放宽 Worker/PWA 验收来掩盖缺陷。香港、上海 Web/API、控制工具和上海下载 stable 随后全部按已验证边界回滚；生产数据库保持 schema v8/layout v3，没有恢复、替换或修改玩家数据。

## 阻断证据

1. 全新系统 Chrome 能以 HTTP 200 加载 1.0.46 根页，页面标题和 React 根节点正常，`version.json` 精确为 `1.0.46+d64b9ef85f9d`。
2. 45 秒内没有 active Service Worker；手动注册同一不可变 Worker URL 后，候选 Worker 在安装阶段变为冗余，未留下 active/waiting/installing Worker。
3. 按生产 `sw.js` 的 `discoverShellAssetUrls()` 逻辑复放公网依赖图，共访问 273 个候选 URL；大量合法依赖被错误扩展为 `/assets/assets/<hashed-file>` 并由生产静态服务器返回 404。
4. 根因位于嵌套 JS/CSS 资产发现：生成代码中的 `assets/<hashed-file>` 字符串以当前 `/assets/<owner>.js` 作为 base 解析，错误得到双层 `/assets/assets/`。`installShell()` 对任一非 2xx 依赖按设计硬失败，所以 Worker 不能激活。
5. 开发 production-preview PWA 3/3 没有捕获该问题；开发静态服务器对未知 hashed asset 的回退行为与生产 Nginx 的严格 404 合同不同，缺少“未知 `/assets/*` 必须 404”的生产等价安装门禁。

这不是制品上传损坏、缓存未刷新、证书问题或 VPS 网络问题。Web 155/155、API 166/166、release-control 8/8 和下载页 9/9 的远端文件清单均与冻结 manifest 一致；1.0.46 APK（5,193,632 bytes）和 Windows setup（109,791,910 bytes）的公网完整 SHA-256、Range 206 与缓存头也在回滚前通过。

## 开发返修门禁

开发 Agent 必须从新提交生成全新 Release ID，不能复用 `1.0.46-d64b9ef85f9d` 或原冻结制品：

1. 修正嵌套资产 URL 解析，明确区分根相对 `assets/...` 与拥有者相对 `./...`，不得产生 `/assets/assets/`。
2. 为 `discoverShellAssetUrls()` 增加入口 JS 位于 `/assets/` 且内部含 `assets/<chunk>`、`./<chunk>`、绝对 `/assets/<chunk>`、CSS `url(...)` 和无关字符串的单元测试。
3. 增加生产等价静态服务器 E2E：未知 `/assets/*` 必须 404，不能回退 `index.html`；全新浏览器必须完成 Worker install/activate、缓存 marker/registry、当前根页离线重开。
4. 在同一浏览器先激活新 stable，再访问 `/canary/previous/`，要求只有当前 Worker active、无 waiting/installing、当前缓存 HTML 前后逐字不变、离线根页仍可重开。
5. 完整重跑 Web/API/ops/release-switch/native、签名连续性、Android 实机或新的明确豁免、两地备份/原子切换、下载完整哈希/Range/cache 与公网观察窗口。

在新候选发布前，当前安全回退是显式保持 1.0.45 Web/API 和 1.0.44 native stable；`--rollback-last` 当前指向被拒绝的 1.0.46，禁止作为恢复命令使用。
