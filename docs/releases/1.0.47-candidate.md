# 1.0.47 发布前候选记录

> 状态：开发与本机门禁完成，未发布；本记录不授权打包、签名、生产访问、流量切换或下载页更新。

## Scope

1.0.47 只处理本轮三项玩家反馈：提供 1.0.43 风格的经典精简建筑卡；修复拖动画布后 Canvas 传送带与建筑错位；修复连线时建筑偶发半透明。没有玩法数值、模拟、存档、云协议、数据库或线上运维变更。

## Implemented

- 基础卡片偏好扩展为 `auto/full/classic/medium/minimal`；设置页按“自动、完整、经典、中等、一行”排列。“经典”使用旧 `FactoryNodeLodView` 的 `224×76` 紧凑结构，“一行”继续使用 `96×32` 卡片。
- `classic` 继续写入既有设备级键 `dsp-idle-network.ui.canvas-detail.v1`，不会进入 GameState、存档、云同步、迁移或确定性哈希；旧设置和值保持兼容。
- Canvas 传送带的受控视口同步只依赖 `x/y/zoom` 数值，并通过 ref 调用最新回调。平移手势中的实时 viewport 保持权威，选择或拓扑重绘不会因回调身份变化重新套用陈旧 prop。
- 画布增加 drawn/live viewport 诊断字段；回归在平移后触发堆叠代表选择和几何重绘，断言 Canvas 有效变换与 React Flow transform 的误差不超过 `0.75px`。
- 连线草稿或点击连线预览活动时，暂停任务、网络、生产链和寻线聚焦的 dim 派生；CSS 兜底覆盖 React 节点提交晚一帧的窗口。取消或完成连线后，原聚焦透明度恢复。
- 发布说明新增中英文 1.0.47 条目，并保留 1.0.46 历史说明；产品版本更新为 `1.0.47`，Android 仅更新元数据到 `1.0.47 / 1000047`。
