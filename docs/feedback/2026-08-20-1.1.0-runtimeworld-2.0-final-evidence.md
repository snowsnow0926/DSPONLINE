## 1. 基线与 1.0.47 融合

- RuntimeWorld 正式开发基线为 `58456b391c4311c0a4969cfe7075c0f47bc75b12`。
- 当前线上兼容基线为已正式发布的 1.0.47：`aab581cf0c78e480e1d10fe4c7f91e6d6d9311b7` / `1.0.47+aab581cf0c78`。
- `07132550abd5df4bd81eb3faa40534ad6cffbf21` 把 1.0.47 的产品差异移植到 1.1.0：
  - 设备级“经典”基础卡片使用 1.0.43 风格 `224×76` 布局；`minimal` 仍为 `96×32`。

## 2. M-1 与 M0～M6 收口

| 阶段 | 最终事实 |
| --- | --- |
| M-1 | raw payload cache 在 dev/preview 各 3/3 于权威提交边界归零；物流 profiler 互斥归因 100%；两档冷基线、命令矩阵、合成形状、1x/4x/11x debt、两档 30 分钟内存与长时前缀均固定；结论 GO |
| M0 | RuntimeWorld phase telemetry 固化，默认关闭；compile、command、invalidation、engine domain、journal、projection、main merge、paint、save 与 IDB write 可分段记录，开关扰动单独对账 |
| M1 | Worker 私有 RuntimeWorld、稳定 slot/generation、domain revision、dirty journal、局部失效、Projection v2 shadow oracle/fallback 与确定性 session 边界完成 |
| M2 | 传送带端点、端口、路由、容量、预留、公平顺序和累计热字段进入编译路径；旧 `transferBelts()` oracle 覆盖时间与拓扑边界 |
| M3 | 生产与供电静态依赖、配方量、scratch 结构和唤醒边界编译；缺料、堵塞、断电/低电、配方和量子边界保持旧结果 |
| M4 | 物流槽位、量子容量、阻断快照、稳定岛跳过与显式 fallback 完成；单核运行移除只供多核合并的无用全量差分 |
| M5 | 模拟、primary persistence、view store 与 canvas presentation 生命周期拆分；Simulation Worker 准备 canonical envelope，Persistence Worker 独立 checksum/CAS/提交/精确读回 |
| M6 | 1.1.0 默认启用 RuntimeWorld，生产不运行 shadow 双跑；旧引擎保留为受控领域 fallback；完整平台门禁和不可变候选完成 |

RuntimeWorld、journal、slot、稳定岛、缓存和 phase telemetry 都是可丢弃 Worker 私有结构，不进入存档、云 payload、排行榜摘要或确定性持久哈希。分块本地存储和 durable WAL 均没有因本版本默认启用。

## 6. 性能门禁的完整失败记录

- 连接视口隔离门禁通过：bounded entry 11.0 ms，P95/max 16.8/16.8 ms，`>50 ms` 为 0。显式 expand-all 诊断 entry 55.4 ms，P95 33.3 ms，max 133.3 ms，`>50 ms` 为 1；该路径是玩家主动高细节诊断，不冒充自动档。
- 密度隔离第一次最终 SHA 执行失败：一个 auto 子轮 P95 33.3 ms、max 33.4 ms，后续子轮回到约 16.8 ms，且没有 `>50 ms` 帧。固定 auto P95 门限仍为 `<=21 ms`。
- 独立新浏览器进程复跑通过：auto 三轮 P95 为 16.8 / 16.7 / 16.7 ms，max 为 33.2 / 16.8 / 33.3 ms，`>50 ms` 均为 0。

第一次失败没有被删除、retry、skip 或阈值放宽替代。Release Agent 若在目标机重复得到 auto P95 超限，应停止发布并单独处理性能门禁。

## 7. Android 启动预算阻断与修复

旧 runtime SHA `07132550abd5` 的首次 Android release 构建在硬预算处失败：菜单闭包 `287,658 B > 286,720 B`，超出 938 B。根因是只在设置页显示的 `NativeUpdateCard` 被 StartMenu 静态导入，因而进入 Android 菜单启动闭包。

修复没有调整预算：`StartMenu` 使用既有 `importWithRecovery` 懒加载该卡片，并用空 Suspense fallback；设置页行为和桌面更新生命周期专项继续通过。最终结果：

- Android sync build menu `286,471 B`，在门限内。
- Web menu `284,843 B`；Desktop menu `284,811 B`。
- `bundleRelease + assembleRelease + lintVitalRelease`：332 tasks，成功。
- 因运行时代码发生变化，`07132550abd5` 及其部分制品全部作废；新 SHA 固定为 `9b2c579cbe0d`。
