## Scope

1.1.0 把持续模拟从反复扫描通用 GameState 对象升级为 Worker 私有 RuntimeWorld：稳定 slot、domain revision、dirty journal、编译式传送带/生产/电力/物流/量子索引、局部命令失效和受控领域 fallback。保存由模拟 Worker 在权威状态旁准备，持久化 Worker 独立校验、CAS、提交和精确读回；画布和保存 UI 只订阅实际变化的读模型。

本候选以已经正式发布的 1.0.47 `aab581cf0c78...` 为线上兼容基线，包含其经典基础卡片、Canvas 实时 viewport、连线草稿去淡化和 PWA release-root 修复。GameState v47、save envelope v2、cloud schema v8、SQLite layout v3、IndexedDB records 和玩法数值均不变。

## Implemented

- RuntimeWorld 在 Worker 内编译实体、线路、站点和供电依赖；运行时索引不持久化，失败时可以从 GameState 重建。
- 非拓扑命令更新目标 slot 和明确依赖，不再无条件完整重建 lookup；结构变化保持原子 revision 边界。
- 传送带继续保持线路数组顺序、公平游标、两阶段容量与尾货语义；无法证明稳定时完整扫描。
- 生产/供电对缺料、堵塞、低电、燃料、配方和拓扑变化精确唤醒。
- 物流站缓存规范槽位、量子容量和阻断快照；稳定岛只跳过已证明无结果的扫描，量子/跨岛/变化快照显式 fallback。
- Simulation Worker 准备 canonical primary/snapshot envelope；Persistence Worker 负责 checksum、proof、CAS、事务提交和 exact readback。
- 自动保存、手动保存、返回菜单和生命周期 primary 意图共用串行协调器；默认存档合同、backup 与 fencing 不变。
- Runtime persistence view store 和 canvas selector store 隔离高频变化；React Flow 外层位置、选择、拖动和无障碍节点保持稳定。
- 1.0.47 的 `classic 224×76`、Canvas live viewport、connection draft 去 dim 与 PWA 子资源根路径全部合入。
- Android 设置页的原生更新卡改为懒加载，使菜单闭包在不放宽预算的情况下通过。
