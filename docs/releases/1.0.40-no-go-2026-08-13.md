## 实机发布门禁发现

### 1. handoff proxy 经软链接静默退出

模板 unit 从 `/usr/local/lib/dsp-idle-release/current/api-handoff-proxy.mjs` 启动。`directInvocation()` 只对字符串路径执行 `path.resolve`；真实入口经软链接时与模块 URL 不相等，代理以 0 退出，systemd 按 `Restart=always` 重试直至 start-limit。改为直接引用不可变控制目录后，4330 才能稳定转发旧 4320。

### 2. 运行目录生命周期删除待切换状态

release switch 写入 `/run/dsp-idle-cloud/active-start.json` 后停止旧 writer。共享 RuntimeDirectory 没有可靠 preserve，待切换状态可在 unit 生命周期变化时消失；新 active entry 随即回退读取尚未发布的 `switch-state.json`，得到 `ENOENT` 并退出。上海实机增加 `RuntimeDirectoryPreserve=yes` 后，此层故障才消失。

### 3. writer lock 所有权错误

release switch 以 root 调用 `flock --nonblock /run/dsp-idle-cloud/writer.lock true`，可留下 `root:root 0644` 文件。新 writer 的 `ubuntu` 用户无法以写方式打开该锁，日志为 `Permission denied`。active unit 以 `Restart=on-failure` 每约三秒重试，真实演练出现重启循环；FakeRuntime 测试没有覆盖真实 UID/GID/umask。

### 4. 旧版恢复与备份窗口不兼容

1.0.39 没有 `/api/ready`，失败恢复仍先等待完整 ready timeout，延迟旧服务恢复。香港旧服务重启还会立即向 COS 创建约 3.2 GB 快照；在 I/O 紧张时 health 和业务请求超时。收口后给香港 1.0.39 增加 `DSP_CLOUD_BACKUP_WINDOW=03:00-04:00` 保护 drop-in，避免普通重启再次触发即时大快照。

### 5. 大备份复制策略不适合 ext4 热节点

两节点 ext4 均不支持 reflink。`preparePreflight()` 的 FICLONE 失败后直接完整复制备份，香港会额外写约 3.2 GB且没有带宽/IOPS 上限。实测默认 Online Backup 让 API 长时间无响应；4 MiB/s 过慢备份又因长读事务保留约 4.5 GB WAL。后续必须支持经过 SHA/大小/inode/mtime 绑定的预置副本或受控 I/O，而不是在切换关键路径内无条件复制。

## 开发返修硬门禁

1. 所有 CLI `directInvocation` 在软链接入口下用 `realpath` 比较，并增加真实软链接启动测试。
2. 明确定义共享 runtime 目录所有权与生命周期；停止任何参与 unit 都不得删除 pending state、proxy status 或 writer lock。
3. release switch 在启动 writer 前以服务 UID/GID安全创建锁文件；配置/权限错误退出 78，禁止 status 1 的无限重启循环，并添加 StartLimit。
4. switch state/pending state 必须在停止旧 writer 前持久、校验并可恢复；正常成功与任一失败后都不得留下相互矛盾的 current、state 或 proxy generation。
5. 旧版无 `/api/ready` 时要立即、显式走 health 兼容，不得先等待五分钟；失败恢复也必须继承备份窗口，不能触发即时大快照。
6. preflight 支持已验证预置副本或有界 I/O；ext4 无 reflink、3.2 GB 合成库、并发写和 WAL 增长必须有测试。
7. 在隔离 Linux 上使用真实 systemd/Nginx、真实 UID/GID 和临时 SQLite 覆盖：正常、proxy symlink、Nginx reload 失败、preflight ready 超时、writer lock 权限、new-start 失败、旧版回滚、重复执行和重启恢复。持续探针与 Nginx 新日志的 502/503/504 必须为 0。
8. 修复后生成新的 clean SHA/Build ID 和全部不可变制品；精确候选 `58d3e6f986ec…` 永久保持 No-Go。
