## 玩家能看到的改进

1. **保存结果说清楚**：浏览器无法真正保存时会明确提示；仅在内存里临时运行的进度可单独导出，不再误报保存成功。
2. **覆盖旧进度前先留恢复点**：云恢复、坏档救援和手动云槽位先确认旧进度可恢复。直接下载使用实际被替换槽位的旧正文；列表显示后远端版本变化也重新判断。槽位、普通/速通模式不符会拒绝写入，坏旧档不会被误当空槽。
3. **取消、换档和重试更可靠**：过期导入/恢复不能覆盖后来选择的工厂；失败文件清掉旧预览，重复确认只准备一次。
4. **中文输入与草稿各归各处**：输入法回车选字不误执行命令；同一编辑器横竖屏切换保留文字和选区，蓝图名、区域名不会带到另一座同 ID 工厂。
5. **菜单与触控顺手**：方向键、Tab、Esc、空格按当前菜单处理；关闭窗口返回原入口。手机长按松手后菜单仍可使用，被打断的手势正常结束。
6. **大字号和浅色更清楚**：紧凑菜单、搜索结果可滚动到达；桌面大字号指标在头栏内横向查看，避免数值竖向裁切。浅色云恢复卡片提高文字对比度。
7. **客户端组件安全补丁**：Windows 更新清单解析 js-yaml 4.3.2、Android 运行组件 8.4.3、Electron 43.8.1；维护历史 Android 签名及 Windows NotSigned 政策。

GameState 47 / envelope 2 / cloud schema 8 / SQLite layout 3 保持，工厂、物资、科技、存档和备份偏好保持。香港 API、数据库以及上海游戏/API 没有随本次更新部署。实际线上 API 文件与它自己的 revision 核对通过，传输契约和完整校验/缺省读取段相同，50 个有效、30 个无效余数边界逐项验证。
