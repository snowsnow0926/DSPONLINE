## 实现与兼容

- `src/game/vanillaSaveConversion.ts` 汇总清单、历史清单与 ID 映射，分别处理物品、建筑、配方、科技和传送带命名空间。预览只扫描引用，确认后复制候选。
- 清理自定义实体、矿点、库存、研究、生产计划和相关线路，混合蓝图保留原版部分。订单按原蓝图版本判断，已支付手合批次和建造预留只退还实际投入。
- 被移除设备中的原版材料回到对应星球托盘，矿机、喷涂器、原版线路和运输机按规则回收。物流路线与量子桥释放预留，供货站货物保留原有计数。
- `contentIdMigration.ts` 共用字段类别表。实体 ID 和制造任务键分别处理，固定端口数组保留位置。回收溢出或残留引用会中止转换。
- `App.tsx` 复用暂停、检查点、快照、主档与注册表事务。快照、主档、配置任一步失败均保留原工厂，配置写入失败会恢复原主档和注册表。可选持久恢复模式绑定同一目标目录。
- 运营中心新增预览、明确勾选和确认按钮。保留前一批 v5 原版物品与带速覆盖、安全改名、旧 ID 迁移和残留安全卸载。版本公告、历史公告、README、作者指南及规范文档已同步。

恢复顺序为重新启用原包、重新载入工厂、在存档页恢复“转回原版前（含全部内容包进度）”快照。新验证均使用合成数据，玩家提供的原始备份文件保留。

## 发布门禁与回退

软件开发验收和本机候选准备已完成。实体 Android 安装/升级、系统输入法、长时与低配检查，以及 Windows 系统 NSIS 安装/卸载向导仍待验收。本候选的 Android 模拟器升级与转换尚待验证。历史版本的豁免仅归属对应版本。Windows 延续既有 NotSigned 策略，下载页已呈现说明。

发布角色需依据本交接核对签名、摘要和设备门禁，检查香港与上海的实际健康状态、磁盘和回退指针，按批准范围完成备份与原子切换，再核对公网版本、缓存、更新源、完整下载和 Range。当前部署目录与备份指针由发布前只读核验确定。

内容回退优先使用已验证的转换前快照，按上述顺序启用配置与恢复。代码回退使用发布前记录的前一稳定目录，数据库回退须采用独立灾难恢复流程。旧源码、历史安装器、玩家存档和本轮冻结制品均保留。发布操作遵循[部署规范](../DEPLOYMENT_OPERATIONS.md)。
