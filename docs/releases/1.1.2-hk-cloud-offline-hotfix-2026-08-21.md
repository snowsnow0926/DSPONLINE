# 1.1.2 香港 Web 云端离线热修（2026-08-21）

## 结论

香港公网 API 没有离线。问题来自 1.1.2 Web 制品的构建平台常量错误：Web 包被以 Android 平台编译，导致浏览器端 cloudApiBase() 恒定返回 null、Web Cookie 会话被禁用，开始菜单显示“云端离线”，并提示“原生应用未配置云服务地址”。同一源码以明确的 Web 构建重新生成后，浏览器恢复为“云端未登录”（可正常显示登录入口）。

## 变更边界

- 仅香港 Web 静态目录原子切换；没有切换 API、上海、下载页或原生包。
- 没有写入账号、云存档正文、排行榜、SQLite、WAL/SHM 或玩家数据。
- 香港 API 保持 api-1.1.1-da53958b860c，Web Build ID 保持 1.1.2+48d70aa5de06。
- 当前 Web：web-1.1.2-48d70aa-cloudfix2；切换 generation：30；pending switch：false。
- 直接 previous 指针保留为 web-1.1.2-48d70aa；该目录标记为原平台误编译版本，不应再次激活。香港 /canary/previous/ 仍指向上一已知稳定 Web。
