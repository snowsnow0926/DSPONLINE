## 最新这一批做成了什么

Rust 和桌面主进程现在能各自识别完整的验证版本：程序文件、内置游戏目录、规则实现和固定基础检查名单。在新 Windows 包里，两边与外部核对得到的十二项身份信息完全一致。

可以理解为，两边既能核对“用的是不是同一本配方表”，也能核对“运行的是哪一份程序、对应哪一套检查”。这是继续接入 Rust 实时计算的基础能力；目前还没有把这些信息变成玩家运行许可，也不代表新增了多少实际提速。

本批运行代码是 **0d7e1e01**，开发包 **1.2.7+0d7e1e01aba0** 已冻结，76 项制品/79 个文件一致，当前未数字签名。[完整实现与验证记录](./reviews/rust-windows-validation-candidate-2026-09-10.md)
