## 发布结论

`1.0.38` 已完成香港、上海 Web/API、上海下载页、Android stable APK 和 Windows stable 测试包发布。两地 Web/API 当前均为 `web-1.0.38-351c649af9ee` / `api-1.0.38-351c649af9ee`，上海下载站为 `download-site-1.0.38-351c649af9ee`。Web/API、下载页和香港 Web-only previous-stable 的直接回滚均为完整 `1.0.37-853ecdb12795`；代码回滚不恢复数据库。

本版把主档、槽位、快照、云上传、普通离线和纯挂机结果改为 Worker 权威序列化、完整性校验和单一可转移缓冲区；传送带、生产、电力、戴森和量子物流在稳定 Worker 请求间复用私有批次与索引；新写出的 v46 JSON 只省略既有迁移会精确补回的默认零值。普通模式中恰好一个健康规范单极磁石节点的暂停存档，可在持久快照、候选哈希、确认令牌和双重确认后补到硬上限两个，不增加矿机、缓存、库存、累计产量或既有储量；速通和异常存档拒绝。GameState v46、存档 envelope v2、云 schema v7、SQLite layout v2 和排行榜协议均未变化。

用户明确豁免精确候选 `1.0.38-351c649af9ee` 的 Android 真机、低配 Windows、`1.0.37 → 1.0.38` Windows 覆盖升级和约一小时后台/锁屏门禁，并接受 60 秒精确模拟 13.5～13.8 秒、移动 Canvas 最大帧 139ms、既有长窗口近似误差和 30 MiB 云上传上限的残余风险。该豁免不等于测试通过，也不适用于后续版本。

## 明确未验证与后续风险

- Android 物理真机、低配 Windows、`1.0.37 → 1.0.38` Windows 实际覆盖升级、约一小时锁屏/后台、温度/耗电和长时内存未执行，由用户只对本候选明确豁免。
- Windows 仍无 Authenticode 证书，继续按公开测试包策略标记 `NotSigned`。
