# 稳定事件和长按取消回调：阻断初始渲染作用域保留

状态：候选已验证并撤回，未发布。接续 [页面保留堆诊断](./2026-10-28-web-main-heap-retention.md)，持续 goal 运行中。

两个独立浏览器用例先在旧实现复现：经过四次新渲染、清理前一 React fiber 并做诊断 GC，初始渲染数据仍被稳定事件/长按 hook 保留。单元函数行为正常不代表旧闭包已经释放。

原因是稳定函数在 hook 内创建，能与同次渲染的 effect/手势回调共用词法环境。即使稳定事件只使用 `callbackRef.current`，该环境仍能保留初始 callback；长按 hook 的稳定取消闭包同样会连带保留 `getTarget`/`onLongPress`。

候选曾把稳定调度和取消函数定义在模块作用域，以原生 `bind` 只绑定必要的 ref。稳定事件仍在 layout effect 后使用最新已提交回调；长按计时器仍保留按下时的回调快照，普通渲染不饿死手势，路由变化/禁用仍取消。没有将所有旧事件改成读取最新状态，也没有改变 App、模拟、T0、保存或恢复代码。

修正后两个浏览器 GC 用例通过；稳定事件身份/行为、长按普通渲染快照和路由取消单元通过，应用类型通过。第一次泛型绑定表达式缺括号导致转换失败，原始日志保留，修正后重跑通过。

随后用同一份大档、两套冻结网页和六阶段 GC/弱引用诊断复核。候选存活视图没有减少：普通模拟预热后旧/候选分别为投影 40/41、画布 44/45、流量 42/43；停止后为 40/41、46/47、41/42。页面 GC 后使用堆在候选中约高 35–42 MB。四次无采样整页对照（旧/新/新/旧）也没有可接受的内存收益：渲染进程峰值中位 **4,647,831,552→4,660,377,600 B（+0.27%）**，浏览器五点工作集 **4,169,857,024→4,181,952,512 B（+0.29%）**；进入长任务累计 **473.5→479.0 ms（+1.16%）**。进入/退出最长帧虽有波动下降，但没有抵消内存退步。候选 hook 变更已撤回，相关小用例和候选测试夹具不进入最终运行树；原始、完整和撤回证据全部保留。

下一步继续沿引用摘要审计真正持有旧视图的 React Flow/画布作用域，优先从 `canvas-snapshot`、`projection-result` 和流量观察的最终消费者入手。没有新的端到端收益前不再改稳定事件或长按 hook，也不从小用例宣称整页内存下降。
