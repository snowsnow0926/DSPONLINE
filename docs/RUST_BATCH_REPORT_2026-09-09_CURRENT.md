## 这批具体改了什么

普通存档已接入 Rust 短离线入口：读取来源、生成结算候选、核对完整结果，再保存并重开。公开大工厂已走通实际游戏流程，取消时也保留原存档。

大存档读取和导出改为有界缓冲，减少大量细碎的磁盘操作。最新导出缓冲固定为 64 KiB，仍检查完整长度、完整内容，写完并同步后才发布文件；输出过长、回调失败等情况不会发布半份结果。保存过程也复用了已经校验的字节数，减少重复编码。

共享计算清理了空星球、电力统计、建设参考规划等重复工作，原来的模拟秒数、扣料顺序和产出规则保持不变。

## 你的终局档现在到哪一步了

原始存档保持不变。之前冻结的 `37630d05` Windows 包已经通过 9 秒 Rust 与完整 JS 结果对照、取消不损档和取消后两次重开。但完成结算后，仍没有在原 90 秒内进入可操作工厂；**成功结算后的持久保存和重进还未验收**。

本次新 Host 的六次计算与独立 JS 全部字段一致，六份实际导出文件的完整字节也相同，每份约 209 MB。六次均正常退出，测试临时数据清理完成。它还没有生成新的 Windows 安装包，不能继承旧包的实际入口验证结果。

另一次无界面分段测量显示：约 52 秒请求中，精确模拟约 24 秒，建立与校验工厂状态约 11 秒。两块是下一步的重点；现有计时没有覆盖所有步骤，余下时间不能全部算作磁盘开销。细节见[最新 Rust 导出证据](./reviews/rust-rp1-export-buffer-2026-09-09.md)和[终局实包记录](./reviews/rust-rp1-private-cancel-2026-09-09.md)。

## 网页、安卓和 Windows 的区别

Windows 开发包已接入受限的 Rust 短离线计算。网页和安卓目前仍使用共享 JS，没有接入本批 Rust 核心；共享代码优化可以随各端后续发布生效。当前仍保持 **1–30 秒采用范围**，长离线自动采用和 Rust 实时接管未开放。

## 后台测试怎么保证不打扰你

本轮只运行无窗口 Node 和控制台 Rust Host，**没有启动游戏窗口**。已检查，没有本任务遗留的游戏进程，你的其他程序未操作。

后续实际界面测试只使用经过验证的隐藏、不可聚焦、静音离屏入口。旧的可见窗口驱动停用；不能确保隐藏的测试暂缓。本机重任务一次一个、低优先级，完整模拟至少有 6 GiB 可用内存才启动，运行时低于 2 GiB 则停止本次测试。测试仍会占用一些资源，因此不会声称完全零影响，也不会关闭你的应用腾内存。
