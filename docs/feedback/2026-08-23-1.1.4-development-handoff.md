## 本次实现

### 1. 建筑制造巨构批处理与多中心公平

- 对有限副产物相位进行最多 8 个作业的确定性探测；只有配方形状和副产物相位回到起点、没有副产物溢出/载具返还且聚合批次可重复时才建立多作业闭环。
- 聚合批次按真实前缀需求合并托盘消耗、返回、副产物、产物和工作时间；不闭环时继续使用原子任务路径，不丢弃 WIP、不凭空生成库存。
- 通过周期相位和起始库存复核保持缓存有效；外部新增材料会使缓存失效，避免新配方被旧计划吞掉。
- 同一行星的多个制造中心共享有界迭代/规划预算，按稳定实体顺序公平分配并返还未使用配额；一个高堆叠中心不能独占整颗行星的保护预算。
- 高堆叠、递归、多副产物与 1/2/3 相位回归均与未批处理 legacy oracle 做状态哈希比较。

### 2. 蓝图传送带数量守恒

- 蓝图需求、放置和排队均保留模板中的显式 `lanes`；`minimumBeltLanes` 仅为旧调用方保留的兼容参数，不再修改蓝图拓扑、库存需求或版本 ID。
- 新绘制传送带仍可使用设备默认并联数量；蓝图部署不再继承该偏好。

### 3. 离线与纯挂机的有界可验证前缀

- 普通快速离线路径在没有有效 30 秒校准候选时，先在隔离副本精确推进最多 1 个模拟秒，再对剩余不确定尾段使用保守结算；若前缀失败才回退零收益并报告具体原因。
- 纯挂机 Worker 连续失败后的保守会话采用同样的 1 秒精确前缀，并保存可恢复的 calibration checkpoint；原主线程状态保持事务性不变。
- UI 不再把保守模式下“尚未从短窗口测得”误标为“未运行”，会说明“短窗口未测得/不确定尾段已冻结”，避免把安全降级误报为存档无效。
- 该策略只发放可验证前缀收益，不外推运输、瞬时功率或其他不确定字段，不改变时间扭曲和速通规则。

### 4. 服务器运行时优化（不改数据协议）

- 已复核 `docs/PERFORMANCE_OPTIMIZATION_PLAN_2026-07.md`：PresenceIndex、LeaderboardSnapshotIndex 和上传检查队列等已有运行时索引/有界机制继续保留。
- 新增运行时 `UserLookupIndex`，在启动和显式 rebuild 时从权威 `store.data.users` 重建；注册、登录、找回密码、邮箱绑定、账号删除和外部 users mutation 都维护索引，`/api/metrics` 只暴露计数诊断。
- 索引命中仍复核权威用户对象；索引缺失/过期时执行一次冷回退扫描并修复索引，因此不会把索引失配变成认证失败。用户名/邮箱规范化与旧路径一致，重复历史邮箱仍保留原有“存在即冲突”语义。
- 不增加唯一约束、不改 SQLite 表、云协议、玩家数据或存档 schema；纯内存 10,000 账号热查找基准通过。API 不可变包补齐索引模块和测试，完整 server/SQLite 与 ops 门禁已经通过。

### 5. 终局存档压缩、低峰值持久化与容量扩展

- v47 稀疏投影只省略迁移器会精确补回的五类非活动实体默认值：零燃料、未安装喷涂机、空物流站模式过渡、空量子过渡和固定五槽全空电梯输出。非零/活动值、库存、WIP、线路、蓝图、量子库存和玩家意图继续逐字段保留。
- 同一真实档重新保存后为 `62,264,191` 字节，比原件减少 `4,989,952` 字节（7.42%）；重新载入后 envelope、checksum、GameState 和完整性检查全部通过，并回到 64 MiB 保证档位以内。
- 大存档自动/手动主档改用模拟 Worker 的 transfer-only 权威检查点：只返回可转移 UTF-8 缓冲和小型状态身份，不再额外 `JSON.parse` 出完整状态镜像，也不再把镜像分块复制回主线程。保存 Worker 以该身份、模式、版本、实体/线路数量和运行时间绑定证明；revision 偏差才回退既有完整重同步。
- 云传输合同从“48 MiB 保证 / 64 MiB 硬上限”扩为“64 MiB 保证 / `96 MiB - 1024 B` 单修订硬上限”。gzip 请求上限 80 MiB、解压后上限 96 MiB、并发展开预算 128 MiB、单档响应上限 208 MiB、客户端最大超时 180 秒、压缩安全超时 30 秒；未压缩兼容兜底仍限制 30 MiB。
- 四份活动 Nginx 模板的 API 请求体上限同步为 `112m`，代理读取超时保持 300 秒；发布时必须先备份配置、远端 `nginx -t`、原子安装并验证回滚，不允许只发布客户端或只提高其中一层。
- 服务端默认单修订配额与同一合同对齐为 `100,662,272` 字节，既有四槽、模式、账号总配额、解压炸弹保护、上传检查队列和原子 revision 语义不变。
