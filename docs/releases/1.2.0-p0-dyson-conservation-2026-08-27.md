# 1.2.0 P0：时间扭曲戴森物料守恒修复报告

日期：2026-08-27
状态：开发与本地门禁完成，未部署、未连接生产、未修改真实玩家存档

## 结论

`pure-idle-macro-v4` 已删除 1.1.8/1.1.9 保守纯挂机把“一秒探针累计结果”按长窗口复制的路径。保守候选只保留最多 1 个模拟秒的隔离精确前缀；后续没有闭合账本的生产、科研、火箭、太阳帆、戴森结构/壳面、银河出口和合同交付全部冻结，只推进游戏时间。实时高倍率近似使用相同的事务性守恒门禁，失败时不再退回大存档的无界整段精确重放。

这会在无法证明物料来源时少发收益，但不会再次用同一批发射井缓存反复增加结构点。戴森功率只在火箭、太阳帆、结构和分星系统计通过守恒后重新派生。

## 客户端守恒门禁

- 火箭：区间发射、银河出口、销毁及已知交付不得超过区间累计生产、期初库存净消耗和明确奖励。
- 太阳帆：发射量必须闭合到期末在轨、吸附、过期及其他已知消耗。
- `structurePoints` 增量必须等于合法火箭发射增量；`shellSails` 增量必须等于吸附增量。
- 各恒星系 `dysonPlans` 和太阳帆轨道增量之和必须分别等于全局增量。
- 库存聚合覆盖托盘、建筑输入输出、传送带/航线在途、物流与空间站槽位、量子库存、施工任务和玩家携带物，并避免重复计数活动行星托盘与航线货物。
- 候选、取消、Worker 重启或保存失败都不能部分提交；源检查点保持不变。

普通离线 Worker 现在每个权威模拟步重新检查取消和现实时间预算；预算已经耗尽时丢弃未提交校准候选，从原检查点做纯时间推进，不在超时后再启动第二段精确前缀。

## 服务端排行榜纵深防护

`leaderboard-integrity-v2` 明确支持 GameState v46/v47，相邻普通主云档 revision 使用 O(实体+线路) 的紧凑火箭/太阳帆账本校验。只有服务端上传检查 Worker 生成的当前账本可被显式信任；玩家存档正文伪造的同名字段会被忽略。

高置信异常只进入 `leaderboardReviewQueue` 并保留上一份有效成绩。系统不会自动封禁账号、关闭登录、删除云档或删除旧成绩。首个 revision、缺少相邻 revision、管理员恢复回退和旧字段不足只标记为无法验证/等待人工复核。
