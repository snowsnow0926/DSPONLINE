## 真实性能与内存证据

测试存档为 `D:/360安全浏览器下载/dsp-idle-save-2026-08-26.json`，44,167,989 字节、45,904 个实体、91,955 条线路，仅做只读测试。惰性实体解析缓存把冷启动估算从 204,737,068 B 降到 132,356,522 B，低于 132,503,967 B 门槛；打开后常驻 Private Bytes 约 170–172 MiB。打开时解析输入会出现约 1.08 GiB 的短暂峰值，这不是常驻内存承诺。

真实档 exact native 推进约 600–696 ms，原 JavaScript 参考约 1,701–1,861 ms，实测约 2.4–2.9 倍；合成档在 8 workers 下约 2.05 倍，`auto` 约 1.98 倍。这个结果只代表本机和该测试档，不能替代 24 小时、多硬件测试。
